# 2.3 のストア画像（8枚）

- 方向：画像そのものが「点線」と「塗り」。01+02 と 04+05 は2枚でつながる（パノラマ）
- 作り方：`bash build.sh`（Chrome で HTML を画像にして、01〜08.png を1つ上のフォルダに書き出す）
  - 書き出しは src の中にできるので、できた 01〜08.png を `appstore-2.3/` へ写す
- `raw23/`：CI の画面の試験（StoreShots・WidgetShots）で撮った本物の画面。見本の予定だけ
- `zoom*.png`・`card.png`：raw23 の写真から切り出した拡大
