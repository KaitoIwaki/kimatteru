# ナレーション（Google AI Studio の音声生成用）

2026-09-27。ずんだもんの声がいまいちだったので、Google AI Studio の音声生成（Gemini の TTS）で作る。
動画は `lukko-promo-base.mp4`（音なし、56.6 秒）。声ができたら、こちらで行ごとに切り分けて、
声が収まらない所だけ動画を伸ばして合わせる（`make-narration.mjs` と同じ考え方）。

## 設定

- 開くページ：**https://aistudio.google.com/generate-speech**（Playground の「Antigravity Agent」ではない。あれはコードを動かすエージェントで、音声には要らない）
- モード：**Single-speaker**（1 人）
- モデル：**Gemini 3.8 Flash TTS**（2026-09 時点。軽い版の Flash-Lite TTS もある。日本語に対応）
- 声の候補（同じ最初の 4 行で聞き比べる）：
  - **Achird**（Friendly）… 親しみやすい。第一候補
  - **Aoede**（Breezy）… 軽やかで明るい
  - **Leda**（Youthful）… 若い感じ。学生向けに合う
  - **Puck**（Upbeat）… 元気な男性寄り
- 書き出し：WAV をダウンロードして `store-assets/promo/narration-gemini.wav` に置く

## 1. Style instructions（話し方の指示。ここは読み上げられない）

```
日本の TikTok で流れる、スマホアプリの紹介動画のナレーションです。
聞き手は 10〜20 代の大学生・高校生・バイトをしている人。スマホを縦にして、流し見しています。

話し方：
- 画面の向こうの一人に話しかける。言葉はです・ます調だが、硬くしない。
  先輩が後輩に「これ、便利なんですよ」とすすめるような、明るくて親しみのある話し言葉。
  売り込み口調・アナウンサー口調・原稿を読み上げている感じにしない。タメ口にもしない。
- 「〜ありませんか？」「〜ですよね」は、本当に相手に聞いているように、語尾を軽く上げる。
- テンポは少し速め（ふつうの会話の 1.1 倍くらい）。ただし一語一語ははっきり。
- 最初の一行は、「あるある」を言い当てる感じ。かぎかっこの中「この予定、決まってたっけ？」は、ひとりごとのように少し声色を変え、
  続く「ってなること、ありませんか？」で見ている人に向き直って聞く。最初の 2 秒で指を止めてもらう、いちばん大事な行。
- 「点線」「塗り」「押すだけ」「すぐ答えられる」「無料」「ぜひ使ってみてください」は、少しだけ強めに、はっきり言う。
- 文の途中で終わる行（「〜聞いてくれて、」「〜見えるし、」）は、次の行へ続くように語尾を下げきらない。
- 「まる」「さんかく」「ばつ」は、ひとつずつ区切って、記号を指さすように言う。
- 最後の「ルッコ」は、アプリの名前として、明るくはっきり。
- 感情を込めすぎない。笑い声・ため息・効果音は入れない。

間（ま）：
- 台本の 1 行ごとに、必ず 1 秒ほど無音の間を空ける（あとで行ごとに切り分けるため。とても大事）。
- 行の中の「、」では短く区切る程度。

読み方：
- 「ルッコ」は「ル」を強めに、「ルッコ」（LUKKO というアプリ名）。
- 「バーベキュー」「アップストア」はカタカナのとおり。
- 数字や記号は台本に書いたとおりに読む。台本にない言葉を足さない。
```

## 2. 台本（Text。このまま貼る。22 行）

行の後ろの `<short pause>` は、そこで間を取らせる印（Gemini の TTS の決まった書き方。読み上げられない）。
あとで行ごとに切り分けるので、必ず残す。間が短すぎたら `<long pause>` に変えてみる。

```
「この予定、決まってたっけ？」ってなること、ありませんか？ <short pause>

ふつうのカレンダーって、ぜんぶ同じ見た目なんですよね。 <short pause>

でもルッコなら、まだの予定は点線、決まった予定は塗り。 <short pause>

決まったら、押すだけです。 <short pause>

「たぶん行く」予定も、そのまま入れておけます。 <short pause>

バーベキューやライブは、まだ点線。 <short pause>

決まったバイトは、塗り。 <short pause>

どれが決まってないか、ひと目で分かるんです。 <short pause>

点線の予定を押すと、「どうなりました？」って聞いてくれて、 <short pause>

「確定した」を押せば、塗りに変わります。 <short pause>

友だちに「いつ空いてる？」って聞かれたら、空き状況のタブを開いてみてください。 <short pause>

毎日に、まる、さんかく、ばつが、自動で付いているんです。 <short pause>

まるは、予定なしの日。 <short pause>

さんかくは、少しだけ空いている日。何時まで空いているかも出ます。 <short pause>

点線のさんかくは、まだ候補しかない日。まだ動かせる、ということです。 <short pause>

ばつは、もう埋まっている日。だから、すぐ答えられます！ <short pause>

しかも、空いている日だけを画像にして送れちゃいます。 <short pause>

予定の中身は相手に見えないので、安心です。 <short pause>

ホーム画面には、ウィジェットも置けます。 <short pause>

何に時間を使ったかも、種類ごとに見えますし、 <short pause>

バイトの給料の目安まで分かります。 <short pause>

未定のまま置けるカレンダー、ルッコ。アップストアで無料なので、ぜひ使ってみてください！ <short pause>
```

## うまくいかないとき

- **行のあいだに間が空かない**：台本の空行をもう 1 行増やすか、Style instructions の「1 秒ほど無音」を「2 秒」にする
- **読み間違える**：その言葉を台本でひらがなに変える（例：「一部」→「いちぶ」）
- **全体が長すぎる（70 秒を超える）**：Style instructions に「全体で 60 秒前後に収まるテンポで」を足す
- **声が途中で変わる**：長い台本だとまれに起きる。前半（1–11 行）と後半（12–22 行）に分けて 2 回作る
