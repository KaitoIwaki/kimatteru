# ナレーション（Google AI Studio の音声生成用）

2026-09-27。ずんだもんの声がいまいちだったので、Google AI Studio の音声生成（Gemini の TTS）で作る。
動画は `lukko-promo-base.mp4`（音なし、56.6 秒）。声ができたら、こちらで行ごとに切り分けて、
声が収まらない所だけ動画を伸ばして合わせる（`make-narration.mjs` と同じ考え方）。

## 設定

- AI Studio → **Generate speech**（音声生成）
- モード：**Single-speaker**（1 人）
- モデル：Gemini の TTS のうち、**Pro**（出来がよい）。遅ければ Flash
- 声の候補（同じ最初の 4 行で聞き比べる）：
  - **Achird**（Friendly）… 親しみやすい。第一候補
  - **Aoede**（Breezy）… 軽やかで明るい
  - **Leda**（Youthful）… 若い感じ。学生向けに合う
  - **Puck**（Upbeat）… 元気な男性寄り
- 書き出し：WAV をダウンロードして `store-assets/promo/narration-gemini.wav` に置く

## 1. Style instructions（話し方の指示。ここは読み上げられない）

```
日本の TikTok で流れる、スマホアプリの紹介動画のナレーションです。
聞き手は 10〜20 代の大学生・高校生・バイトをしている人。スマホを縦にして、流し見しています。

話し方：
- 友だちに「これ便利だよ」と教えるような、明るくて親しみのある声。売り込み口調・アナウンサー口調にしない。
- テンポは少し速め（ふつうの会話の 1.1 倍くらい）。ただし一語一語ははっきり。
- 最初の一行「この予定、決まってたっけ？」は、ふと思い出したような軽い問いかけ。語尾を上げる。
- 「点線」「塗り」「押すだけ」「すぐ答えられる」「無料」は、少しだけ強めに、はっきり言う。
- 「まる」「さんかく」「ばつ」は、ひとつずつ区切って、記号を指さすように言う。
- 最後の「ルッコ」は、アプリの名前として、明るくはっきり。
- 感情を込めすぎない。笑い声・ため息・効果音は入れない。

間（ま）：
- 台本の 1 行ごとに、必ず 1 秒ほど無音の間を空ける（あとで行ごとに切り分けるため。とても大事）。
- 行の中の「、」では短く区切る程度。

読み方：
- 「ルッコ」は「ル」を強めに、「ルッコ」（LUKKO というアプリ名）。
- 「バーベキュー」「アップストア」はカタカナのとおり。
- 数字や記号は台本に書いたとおりに読む。台本にない言葉を足さない。
```

## 2. 台本（Text。このまま貼る。22 行、1 行ごとに間を空けて読む）

```
この予定、決まってたっけ？

ふつうのカレンダーって、ぜんぶ同じ見た目なんですよね。

ルッコなら、まだの予定は、点線。決まった予定は、塗り。

決まったら、押すだけ。

たぶんの予定も、未定のまま置いておけます。

バーベキューやライブは、まだ点線。

決まったバイトは、塗り。

どれが未定か、ひと目で分かります。

点線の予定を押すと、「どうなりました？」って聞いてくれる。

「確定した」を押せば、塗りに変わります。

「いつ空いてる？」って聞かれたら、空き状況のタブへ。

毎日に、まる、さんかく、ばつが、自動で付きます。

まるは、予定のない日。

さんかくは、一部あいてる日。何時まで空いてるかも出ます。

点線のさんかくは、まだ候補しかない日。

だから、すぐ答えられる。

空いてる日だけを、画像にして送れます。

予定の中身は、相手には見えません。

ホーム画面には、ウィジェットも。

何に時間を使ったかも、種類ごとに見えます。

バイトの給料の目安も。

未定のまま置けるカレンダー、ルッコ。アップストアで、無料です。
```

## どの行が、動画のどこか（合わせるときの目安）

| 行 | 動画の場面 | 伸ばす前の秒 |
|---|---|---|
| 1 | 問いかけ（人と「？」） | 0.3 |
| 2 | ぜんぶ同じ見た目 | 3.6 |
| 3–4 | 点線と塗り（BBQ が塗りに） | 7.0 / 9.2 |
| 5–8 | 月のカレンダー（点線・塗りに寄る） | 11.5 / 13.5 / 15.5 / 17.4 |
| 9–10 | 「確定した」を押す | 19.5 / 22.2 |
| 11 | いつ空いてる？ | 25.4 |
| 12–16 | 空き状況（○ → △ → 点線の△ → ×） | 28.5 / 30.6 / 32.8 / 35.0 / 37.0 |
| 17–18 | 空いてる日を送る | 38.9 / 40.9 |
| 19 | ウィジェット | 44.2 |
| 20–21 | まとめ（時間と給料） | 47.5 / 51.2 |
| 22 | 締め | 53.0 |

## うまくいかないとき

- **行のあいだに間が空かない**：台本の空行をもう 1 行増やすか、Style instructions の「1 秒ほど無音」を「2 秒」にする
- **読み間違える**：その言葉を台本でひらがなに変える（例：「一部」→「いちぶ」）
- **全体が長すぎる（70 秒を超える）**：Style instructions に「全体で 60 秒前後に収まるテンポで」を足す
- **声が途中で変わる**：長い台本だとまれに起きる。前半（1–11 行）と後半（12–22 行）に分けて 2 回作る
