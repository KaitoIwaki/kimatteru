# LUKKO マーケティング（分析 → 施策 → 制作 → 投稿 → 効果測定 → 改善）

毎日のサイクルとルールは、会話で決めたとおり。外に出る操作（投稿・送信・公開）は、必ず本人の承認を得てから。
数字が取れないときは推測で埋めず「取得できなかった」と書く。

## 基本情報（随時更新）

| 項目 | 内容 |
|---|---|
| サービス概要 | 決まった予定は塗り、まだの予定は点線。「未定のまま置ける」iPhone のカレンダー |
| ターゲット | ①学生（18〜22）：バイト・サークル・遊びの「まだ決まってない」予定が多い。空いてる日を聞かれて答えるのが面倒。バイトの給料も見たい<br>②社会人（20代〜）：会議の仮押さえ・飲み会の候補日。予定を外に出したくない |
| 訴求ポイント | ①点線→塗りで「決まった？」がひと目で分かる<br>②空いてる日を、予定の中身を見せずに画像・文字で送れる（○△×）<br>③アカウント登録なし・通信しない・広告なし（会社の予定も外に出ない） |
| 競合・類似 | iPhone 標準カレンダー、Google カレンダー、TimeTree、シフト管理アプリ（シフトボードなど） |
| ゴール指標 | **週の新規ダウンロード 100**（App Store Connect の First-time downloads、直近7日の合計）。補助：ストアのページ表示 → ダウンロードの率 |
| 使用チャネル | X・TikTok・Instagram は本人のアカウントはあるが、**LUKKO 専用のアカウントはまだ無い**（作るのは本人）。学生向けストアページ（ppid=6a38f581-…）は学生向けの投稿・広告に貼る |
| トーン | やさしく、短く。説明より「あるある」から入る |
| NG 表現 | 「No.1」「必ず」などの言い過ぎ／他社を下げる言い方／まだない機能を言う／実在の人の名前・顔を画像に出す／「通信しない・アカウントなし」と矛盾すること |

## 数字の取り方

| 見たいもの | 取り方 | 遅れ |
|---|---|---|
| ダウンロード・ページ表示・セッション | `node tools/asc.mjs stats`（API。依頼は `stats setup` で1回だけ） | 1〜2日 |
| ダウンロード数・応援の売上 | App Store Connect の売上とトレンド | 前日分が翌日 |
| 学生向けページの効果 | App Analytics でカスタムプロダクトページ別に見られる | 1〜2日 |
| SNS の再生・いいね・保存・プロフィール遷移 | 各 SNS のインサイト（本人がスクショか数字を共有） | 当日 |
| アプリ内の使われ方 | **取っていない**（解析を入れない約束。入れない） | — |

Google Analytics は使っていない（アプリにもサポートページにも入れていない）。
