# LUKKO Pro（課金の設計）

2026-09-16 に決めた（17 日に「未定の期限」を入れ、CSV を外した）。作るのは 1.3。1.2（まとめ・.ics・取り込みの画面・ガラス）は無料のまま先に出す。

## 一言で

**買い切り 1 つ。¥800。バイトの人の「細かいところ」と、未定を深める 1 つ。**
確定／未確定は永久に無料。投げ銭は別枠で残す。サーバーは使わない。

## なぜこの形か

| 決めたこと | 理由 |
|---|---|
| **買い切り（非消耗型）** | このアプリの約束（広告なし・通信なし・縛らない）に合う。定期購読は解約と更新の面倒がつき、「使い続けるのにお金がかかる」と思われる |
| **1 つだけ** | 松竹梅にすると、比べるための説明が要る。説明が一気に出る画面は、本人がいちばん嫌うもの |
| **¥800** | コーヒー2杯。投げ銭の真ん中（¥600）より上、¥1,000 より下。「機能を買った」と感じる最低の線 |
| **投げ銭は残す** | 動機が別（応援 vs 機能）。消したら、いま応援してくれる道が消える |
| **サーバー無し** | 買った印は端末に持つ。StoreKit の「購入の復元」で機種変更に耐える。約束を変えずに済む |

**消耗型で機能を解放してはいけない**（前に確かめた審査の決まり）。だから投げ銭とは
別の商品を作る。プラグイン（`@capgo/native-purchases`）は `productType` と `restorePurchases` に対応済み。

## 無料の線（ここは動かさない）

- 確定／未確定、カレンダー、空き状況、まとめ、給料の目安、.ics、控え、ウィジェット —— **いまあるものは全部無料のまま**
- 一度出した機能を有料に下げない。信用を一度で失う

## Pro に入れるもの（3 つ。増やすなら 1 つ減らす）

### 1. 割増と交通費　← 最初に作る

いまのまとめは「割増や交通費は入っていません」と**自分で書いている穴**。ここを埋める。

- バイト先ごとに：深夜割増（率・時間帯、既定 25%・22:00〜5:00）、休日割増（率、既定 0%）、交通費（円／日）
- 計算は `wage(ev)` の 1 か所。実働を深夜の帯で切って、率を掛けて足す。交通費は実績 1 件につき 1 回
- 表示：まとめの給料の箱に「うち深夜 ¥1,240・交通費 ¥2,000」の行。詳細カードの金額も同じ道を通す
- **法定の率（25%・35%）は書かない。** 本人が入れる。法律の解釈をアプリが引き受けない

### 2. 上限までの残り

「今年あといくら稼げるか」。扶養の線。

- まとめの年タブ、「使い始める前の額」の隣に「今年の上限」（円）。本人が入れる
- 大きい数字の下に「上限まで あと ¥312,000」。超えたら「上限を ¥12,000 超えています」
- **税や扶養の助言はしない。** 金額の意味も説明しない。「103万」「130万」の数字をアプリが出さない（毎年変わる。書いた瞬間に古くなる）

### 3. 未定の予定に「いつまでに決める」　← Pro の顔

いまの 1 と 2 はバイトの人向けで、**バイトをしていない人に Pro を買う理由が無かった。**
これはアプリの核（未定）を深める唯一の案なので、全員に効く。

- 未確定の予定だけに「いつまでに決める」の行。既定は無し。札で選ぶ：前日／3日前／1週間前／日付を選ぶ
- 期限の朝に通知 1 本：「まだ決まっていない予定が 3 件あります」（件数だけ。中身は開いてから）
- 期限を過ぎた未定は、カレンダーの点線に小さな印（**色は増やさない**。点線の角に点 1 つ）
- 空き状況の一覧の「まだ候補なので調整できます」の行に「◯日までに」を添える
- データ：`e.decideBy = {y,m,d}`。通知は `notify.js` の `syncReminders` に相乗り（iPhone だけ。ブラウザでは印だけ）
- **期限が来ても、勝手に確定にも無くなったにもしない。** 決めるのは本人

CSV は外した。「PC で見たい」の半分は .ics で済むようになったため。欲しい声が出たら 4 つ目の候補。

## 買う画面

設定 → 「バイトと給料」の下に 1 行「**LUKKO Pro**」。押すとシート。

```
LUKKO Pro                                  ¥800・買い切り

  ● 深夜と休日の割増、交通費
  ● 今年の上限までの残り
  ● 未定の予定に、いつまでに決めるか

  [ ¥800 で買う ]
  購入を復元する

  一度買えば、ずっと使えます。
```

- 3 行と 1 つのボタン。説明を足さない。各機能の説明は、その機能の画面にある
- 買ったあと：行が「LUKKO Pro ✓」になり、シートは開かない
- 「購入を復元する」は必ず置く（3.1.1 の決まり。機種変更で要る）

## 買った印の持ち方

```js
settings.pro = { at: 1758000000000, txn: '2000000123456789' }   // 買った時刻と取引ID
```

- 買った瞬間に書く。**起動のたびに StoreKit へ問い合わせない**（通信を増やさない。オフラインでも Pro のまま）
- 「購入を復元する」を押したときだけ `restorePurchases()` → 印を書き直す
- 印が無いとき、Pro の機能の入口は**見えるが押すとシートが開く**（隠さない。何が Pro か分からないと買われない）
- 控え（バックアップ）に印を入れない。復元は Apple に聞く道だけ。印をコピーして配れる形にしない

## 出す前に直すもの

1. **審査メモ**：いまは「課金は投げ銭のみ。機能は解放しない」と書いてある。**このまま出すと嘘になる。** 「Pro は非消耗型で、割増・上限・CSV を解放する。投げ銭は別で、こちらは何も解放しない」に
2. **規約**（`docs.js`）：応援の項の隣に Pro の項。買い切りであること、返金は Apple の窓口、復元の方法
3. **App Store Connect**：非消耗型の商品 `com.kimatteru.app.pro` を作り、スクショ・名前・説明。**本体と同じ提出に入れる**（1.0 で置き去りにした失敗）
4. **`asc.mjs status`** の課金の数を 3 → 4 に

## 作る順

1. 商品を App Store Connect に作る（非消耗型・¥800）— 30 分
2. 買った印と復元、設定の 1 行とシート — 半日
3. 割増と交通費（データ・計算・まとめの行）— 1 日
4. 上限までの残り — 半日
5. 未定の期限（行・通知・印） — 1 日
6. 審査メモ・規約・原稿 — 半日

## やらないこと

- **Web 版の同期を Pro にしない。** 同期はサーバー・アカウント・約束の書き換えで、課金の話ではなく別の製品の話
- 定期購読。広告。無料の機能を有料に下げること
- 「Pro でできること」の長い説明。3 行で言えないものは入れない
