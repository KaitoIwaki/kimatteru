# App Store 提出用メタデータ

App Store Connect の入力欄にそのまま貼れる形でまとめています。
**[ ]** が付いた箇所だけ、あなたの情報に置き換えてください。

## 基本情報

| 項目 | 値 |
|---|---|
| App名（30字以内） | `決まってる？ 予定とシフトのカレンダー` |
| アイコン下・アプリ内の表示名 | `決まってる？` |
| サブタイトル（30字以内） | `決まった予定と、まだの予定が一目でわかる` |
| バンドルID | `com.kimatteru.app` |
| SKU | `kimatteru-ios-001` |
| 主カテゴリ | 仕事効率化 |
| 副カテゴリ | ライフスタイル |
| 年齢制限 | 4+ |
| 価格 | 無料 |
| 言語 | 日本語（プライマリ） |

> **名前を二段にしている理由。**
> App名の欄は検索で一番重いフィールドなので、ブランドだけで使い切るのはもったいない。
> `決まってる？` で検索する人はいない以上、ここに `予定` `シフト` `カレンダー` を足す
> （全19字。上限30字に収まる）。
> 一方 **アイコンの下に出るのは `Info.plist` の表示名**で、検索とは無関係。
> こちらは `決まってる？` だけ。合印の `✓？` と対になる、この名前の本体。
>
> **英語名は検討して見送った。**（2026-08 時点で App Store を検索）
> `Ink` … カレンダーアプリが使用中／`Inkwell` `Inku` `Maybe` … 別ジャンルで使用中／
> `Penciled In` … 空き。一度これに決めたが戻した。理由は `app/README.md` の冒頭に書いてある——
> 要は **ASO は改善しないまま、言いやすさと `✓？` との一致だけを失う**取引だったため。

## プロモーションテキスト（170字以内・審査なしで差し替え可）

```
決まっている予定は塗り、まだ分からない予定は点線。カレンダーを開いた瞬間に、予定の「確かさ」が見えます。バイトのシフト管理と給料の記録にも。
```

## 説明（Description）

```
「この予定、決まってたっけ？」をなくすカレンダーです。

ふつうのカレンダーは、確定した予定も「入るかもしれない予定」も同じ見た目で並びます。だから、パッと見ただけでは区別がつきません。

決まってる？ は、そこだけを解きました。決まった予定はペンで書いたように、まだの予定はえんぴつのように。

■ 塗りと点線で、ひと目でわかる
決まっている予定は色で塗られた棒。まだ分からない予定は点線の棒に「？」。日常の予定はほとんど塗りなので、たまにある点線だけがふっと浮いて見えます。

■ 決まった瞬間を、手続きにする
点線の予定をタップすると「どうなりました？」と聞かれます。時間を確かめてから、決まった／無くなった／まだ分からない の3つから選ぶだけ。点線が塗りに変わる一瞬が、予定が決まった実感になります。
「無くなった」予定は消えません。取り消し線で静かに残ります。

■ バイトのシフトと給料
働いたあとに実働時間を記録すると、時給から給料を計算します。金額はふだん表示されません。カレンダー上部の「給料」を押したときだけ現れる、隠れたレイヤーです。

■ 空き状況を、自動で○△✕
予定から「終日空き」「一部だけ空き」を自動で判定します。「17:00までなら空いてます」まで教えてくれるので、誘われたときにカレンダーを見返す手間がありません。手動で直すこともできます。

■ 予定の中身は見せずに、空いてる日だけ共有
空いている日だけを示した画像を作れます。予定の名前も時間も含まれないので、何をしているかは相手に伝わりません。

■ 静かな見た目
紙のような地に、墨色の文字。色を持つのは予定だけ。ダークモードにも対応しています。

■ データはこの端末の中だけに
アカウント登録はありません。入力した予定は端末の中だけに保存され、外部に送信されることはありません。利用状況の収集も広告もありません。

--
給料計算は入力した時給と実働時間にもとづく目安です。深夜手当や割増、控除は含みません。
```

## キーワード（100字以内・カンマ区切り・スペースなし）

```
仮予定,未定,点線,掛け持ち,バイト,アルバイト,給料,給料計算,時給,勤怠,予定管理,予定表,スケジュール,手帳,空き時間,日程調整,シフト管理,シフト表,副業
```

> 81字。**「予定」「シフト」「カレンダー」はキーワードから外してある** —
> App名にすでに入っており、Apple は App名・サブタイトル・キーワードをまとめて索引するため、
> 重ねて書くとその分の枠を捨てることになる。空いた枠は `掛け持ち` `仮予定` `点線` など、
> このアプリにしか当てはまらない語に回している。

## App Reviewに関する情報（審査担当者向けメモ）

```
本アプリはアカウント登録不要で、すべての機能をそのままお試しいただけます。ログイン情報は不要です。

・起動直後は予定が空の状態です。画面下中央の「＋」から予定を追加できます。
・「この予定は」で「まだ不確定」を選ぶと、カレンダー上に点線で表示されます。
・点線の予定をタップすると確認ダイアログが開き、確定・取り消し・保留を選べます。
・「バイト」種別の確定した予定は、終了時刻に実働記録を促すローカル通知を出します（設定でオフにできます）。
・データはすべて端末内（ローカル）に保存され、サーバー通信は一切ありません。
```

## プライバシー（App Privacy）の回答

**「データを収集していません（Data Not Collected）」を選択してください。**

根拠：
- アカウント登録なし。氏名・メール・電話番号などを一切取得しない
- 解析ツール・広告SDKを一切組み込んでいない
- ネットワーク通信を行わない（外部APIなし）
- 予定・時給・設定はすべて端末内の localStorage に保存
- 通知はローカル通知のみ。画像共有はユーザーが共有シートで選んだときだけ実行
