# LUKKO を社会人にも選ばれるアプリにするために足りないこと

## 1. 結論

- LUKKO のいちばんの強みは「まだ決まっていない予定を点線のまま置ける」ことです。これは会社員が毎日している「仮押さえ」と同じなので、本当は社会人にこそ効きます。
- ところが今は、最初の画面（「用事・バイト・遊び」の種類、「カフェバイト」の見本、月表示の「給料」スイッチ）も、画面の言葉も、ストアの画像と文も、学生とバイトの暮らしに合わせて作られています。そのため社会人は、最初の数秒で「自分向けではない」と判断してしまいます。
- 仕事の予定を預けるための土台も足りません。会社のカレンダーとのつながり、時刻の見え方、空き状況で見る時間帯、予定が消えない安心の4つです。
- 進める順番は次のとおりです。
  1. 言葉・見本・ストアを社会人向けにする（手間は小さい）
  2. 入力と空き状況を社会人の時間に合わせる
  3. 取り込みと控え（バックアップ）で「預けて大丈夫」を固める
  4. 週表示・重ねて表示・iCloud 同期などの大きい工事に進む

## 2. まずやるべき 10 個

### 1. 「仮押さえ」を LUKKO の言葉にする（効き:大・手間:小）
- なぜ：点線は、会社員が毎日口にする「仮押さえ」そのものです。なのに、画面にもストアにもこの言葉が一度も出てきません。
- どう直す：
  - 仕事の種類では、呼び名を「仮押さえ／確定」、問いかけを「この仮押さえ、どうなった？」にする。
  - ストアのサブタイトル・キーワード・プロモーションテキストにも入れる。プロモーションテキストは審査なしで今日変えられます。

### 2. 最初に「どんな使い方？」を1問だけ聞く（効き:大・手間:中）
- なぜ：開いてすぐ「用事・バイト・遊び」と「？カフェバイト」が並ぶと、社会人はそこで閉じてしまいます。
- どう直す：
  - 「学校とバイト／会社の仕事／シフト勤務／子育て・家族」から選んでもらう。
  - 答えに合わせて、最初の種類・呼び名・見本・入力例・給料の表示・空き状況で見る時間帯を切り替える。
  - あわせて、種類を隠す・並べ替えることもできるようにする。

### 3. 月表示の「給料」スイッチは、バイトをしている人にだけ出す（効き:大・手間:小）
- なぜ：毎日開く画面のいちばん目立つ所が「バイト用のアプリ」と言ってしまっています。
- どう直す：バイト先か働いた記録が1件でもあるときだけ出します。空いた場所には、今月以外を見ているときだけ出る「今日」ボタンを置きます。

### 4. ストアの画像と見本を「社会人の1か月」で撮り直す（効き:大・手間:中）
- なぜ：最初の3枚すべてに「バイト」が写っています。ストアで見てもらえるのは2秒ほど（monetization-plan.md）なので、その間に学生向けだと判断されます。
- どう直す：
  - demo.js に社会人の見本を足し、1〜3枚目を撮り直す。
  - 「通信しない・アカウントなし」を伝える1枚を足す。
  - 学生向けの画像は、後ろに回すか別の店頭（後で説明するカスタムプロダクトページ）へ移す。

### 5. 空き状況を社会人の時間に合わせ、文字でも送れるようにする（効き:大・手間:中）
- なぜ：今は9〜22時の固定で判定しています。そのため会社員の平日は、全部○か全部△になってしまい、空き状況が役に立ちません。それに、社会人の日程調整は文字でやりとりするのが普通です。
- どう直す：
  - 設定に「いつもの勤務時間」と「空きを見る時間（平日と休日で別々）」を置く。
  - 「10/3（金）19時以降／10/4（土）終日」のような文を1タップでコピーできるようにする。
  - 画像も、空き状況と同じ判定で作る。

### 6. 毎日の入力でつまずく所を2つ直す（効き:大・手間:小）
- なぜ：
  - 10:00–11:00 の予定の開始を14時に動かすと、終わりは11:00のまま残り、「14時〜翌11時」の予定ができてしまいます。
  - 未定の予定を押すと、中身より先に「どうなりました？」が出ます。
- どう直す：
  - 開始を動かしたら、長さを保ったまま終了も一緒に動かす。
  - 先の日付の未定の予定は、押したら詳細画面を開く。「どうなった？」は詳細画面の主ボタンから聞く。

### 7. 候補日をまとめて置き、1つ決めたら残りを片づける（効き:大・手間:中）
- なぜ：「候補を3つ押さえて1つに決める」は社会人の日程調整そのものです。未定を置けるこのアプリがいちばん生きる場面なのに、今は1つ確定しても残りが点線のまま残ります。
- どう直す：
  - 複数日で仮に置くとき、「どれか1日に決まる」を選べるようにする。
  - 1つ確定したら「ほかの候補2件を片づけますか？」と聞く。

### 8. 取り込みを、仕事の予定で使える形にする（効き:大・手間:中）
- なぜ：今の取り込みには次の問題があり、最初の5分で「使えない」と思われます。
  - 場所とメモ（会議のリンクなど）が落ちる。
  - 取り込み直すと予定が二重に残る。
  - 「勤務」「出勤」を含む予定がバイトとして扱われる。
- どう直す：
  - 場所・メモ・日数も写す。
  - 元の予定の番号を残し、取り込み直したときは「新しい予定」ではなく「更新」として扱う。
  - 取り込むカレンダーを選べるようにする。
  - 仕事の言葉は「仕事」の種類へ当てる。
  - そのあとで「重ねて見る」に進む。

### 9. 予定が消えない安心をつくる（効き:大・手間:小）
- なぜ：「予定はこの端末の中だけ」「ときどき控えを取ってください」だけでは、仕事の予定を預けてもらえません。
- どう直す：
  - 1日1回、日付つきの控えを端末の中に何日分か自動で残す。設定には「最後の控え」の日を出す。
  - 実機で確かめたうえで「iPhone ごと移せば、予定も移ります」とはっきり書く。
  - 起動したときに古いほうの保存から始まることがある問題も、一緒に直す。

### 10. 毎日開く理由をつくる：朝のまとめ通知と、進むウィジェット（効き:大・手間:小）
- なぜ：通勤中に今日の予定を見る習慣がつかないカレンダーは、すぐ消されます。また、今のウィジェットは1日1回しか描き直さないので、朝の会議が夕方まで先頭に出続けます。
- どう直す：
  - 「朝のまとめ」通知を作る（例：今日3件、うち仮押さえ1件）。
  - ウィジェットが、時間に合わせて次の予定へ進むようにする。
  - その次に、ロック画面用のウィジェットを足す。

**次の候補（どれも手間が小さく、効くもの）**
- 評価をお願いする（iPhone 標準の星の小窓を使う）
- 1件の予定を文字と .ics ファイルで送れるようにする
- Web 会議のリンク欄を作り、メモの中のリンクも押せるようにする
- 時給を変えても、過去の給料が変わらないようにする
- 予定の画面の日付のずれを直す（8/30〜9/2 の予定を9月1日から開くと「9月30日」と出る）
- 「バイト先」を「勤務先」に替える
- ダークモードを iPhone の設定に合わせる

## 3. 全部の一覧

### 機能

#### 予定の見え方
- **週表示と、時刻の目盛りがある日表示がない**（効き:大・手間:大）— 今：見え方は月表示だけ。日の画面は、目盛りのない一覧。→ 直し方：見出しに「月｜週」の切り替えを置く。週表示は7列×時刻にし、確定は塗りの箱、仮は点線の箱で出す。日の画面にも目盛り表示を足し、何もない時間を押すとその時刻から予定を作れるようにする。（誰に：会議の多い会社員・フリーランス）
- **今日から先を並べた「これから」の一覧がない**（効き:大・手間:中）— 今：先の予定を見るには、1日ずつ開くしかない。→ 直し方：「今日・明日・今週・来週」の見出しで、時刻と場所つきで並べる。いちばん上には「まだ決まっていない N 件」をまとめて出し、「仮だけ」の絞り込みも付ける。（誰に：会社員・シフト勤務・子育て中）
- **「まだ決まっていない予定」だけを見渡す場所がない**（効き:大・手間:中）— 今：月表示には未定の件数も出ない（ウィジェットにだけ「まだ N 件」が出る）。→ 直し方：月表示の見出しに「まだ 4」の札を置く。押すと、未定の予定を日付順に並べた一覧が開き、各行で「決まった／無くなった／まだ」を選べる。（誰に：全員）
- **予定を検索できない**（効き:中・手間:中）— 今：どの画面にも検索の入口がない。詳細画面に、同じ題名の「前回」が出るだけ。→ 直し方：見出しに虫めがねを置き、題名・場所・メモで探せるようにする。結果は「これから」と「過去」に分けて日付順に並べる。（誰に：予定が多い人・長く使う人）

#### 未定・候補日
- **候補日を並べて、1つに決めたら残りを片づける仕組みがない**（効き:大・手間:中）— 今：「複数日」で置いた予定は、それぞれ別の予定になる。1つを確定しても、残りは点線のまま。→ 直し方：仮で複数日に置くとき「どれか1日に決まる（候補日）」を選べるようにする。1つ確定したら「ほかの候補2件を片づけますか？」と聞く。帯には「候補 1/3」と出す。運動会の「本番＋予備日」のような言い方も用意する。（誰に：幹事役・会社員・子育て中）
- **日にちがまだ決まっていない予定を置けない**（効き:大・手間:大）— 今：予定は必ず日付を持つ。→ 直し方：日にちに「まだ決めない」を足し、「今週のどこか／今月のどこか／来月あたり／いつか」から選べるようにする。月表示の上に「今月のどこか 3件」の棚を出し、日が決まったらそこからマスへ移す。（誰に：通院・美容院・帰省などを抱える20代後半〜30代）
- **「延期になった（別の日になった）」を選べない**（効き:大・手間:中）— 今：「どうなりました？」の答えは「確定した／無くなった／まだ分からない／内容を直す」の4つだけで、小窓では日付を変えられない。→ 直し方：「別の日になった」を足し、小さなカレンダーで新しい日を選ぶか、日にち未定の棚へ移す。元の日には薄く「→ 延期」と残す。「···」にも「日にちを変える（翌日・翌週・日を選ぶ）」を入れる。（誰に：会社員・子育て中）
- **「19時から、終わりは未定」「土曜の午後」のように、時刻の一部だけ未定の予定を置けない**（効き:中・手間:中）— 今：開始と終了が必ず要る。未定にできるのは予定まるごとだけ。→ 直し方：終了に「未定」、開始に「午前・午後・夜」を選べるようにする。表示は「19:00〜」とし、空き状況では△として扱う。（誰に：会食・飲み会の多い会社員）
- **仮押さえに「いつまでに決める」の期限がない**（効き:大・手間:中）— 今：Pro の計画（pro-plan.md）にあるだけで、コードにはまだない。→ 直し方：「前日／3日前／1週間前／日付を選ぶ」を持たせ、期限の日の朝に「今日までに決める仮押さえが2件あります」と知らせる。紹介するときの例は、結婚式の出欠や旅行の申し込み締切など、社会人の場面にする。（誰に：営業・人事・幹事役）
- **何人かの候補日に、相手が○△×で答えられる場所がない**（効き:中・手間:大）— 今：NEXT.md と design-handoff.md の依頼 C に、保留として書いてあるだけ。→ 直し方：候補日を「リンクで送る」を作る。中身はリンクの「#」より後ろに入れ、ページを置いている側にも届かない形にする。受け皿は GitHub Pages の置くだけのページにする。相手はアプリなしで○△×を押し、結果を文字で返す。幹事がそれを貼ると、候補ごとの○の数が出る。ページの下には「LUKKO で作成」を入れる。（誰に：幹事役・家族の予定を合わせる人）
- **就活・転職の選考日程に合う形がない**（効き:中・手間:中）— 今：「就活」の種類も、締切の印も、「結果待ち」の印もない。→ 直し方：種類の見本に「就活（選考）」を用意し、呼び名を「候補日／面接確定」にする。締切を1つの印で置けるようにし、結果待ちを未定のまま持てるようにする。（誰に：就活生・転職活動中の会社員）

#### 空き状況と共有
- **空き状況で見る時間が9〜22時の固定で、平日と休日の区別も、いつもの勤務時間もない**（効き:大・手間:中）— 今：勤務を予定に入れていない会社員は平日が全部○になり、入れていれば全部△になる。→ 直し方：設定に「空きを見る時間」を平日と休日で別々に置く（例：平日19〜23時、休日10〜22時）。「いつもの勤務時間」（曜日ごと、例：月〜金 9:00〜18:00）を一度入れれば、その時間はふさがっている扱いにする。祝日は休日として数える。「会社の仕事」を選んだ人には、最初から値を入れておく。（誰に：会社員・シフト勤務）
- **空いてる日を文字で送れない**（効き:大・手間:小）— 今：シェアは画像だけ。→ 直し方：「文字でコピー」を足し、「10/3（金）19時以降／10/4（土）終日」の形でコピーする。範囲は「今週・来週・2週間・来月」から選べ、「平日の夜だけ」「休日だけ」でも絞れるようにする。ていねいな版（「以下の日程でいかがでしょうか」）も用意する。空き状況の△に付いている一言（「17:00以降なら空いてます」）は、そのまま使える。（誰に：幹事・営業・日程を調整する人）
- **空いてる日の画像が、空き状況の画面と食い違う**（効き:中・手間:小）— 今：次の5つのずれがある。
  - 確定の予定が1件でもあると、時刻に関係なくその日が灰色になる
  - △の時間帯が画像に出ない
  - 手で直した○△×が入らない
  - 過ぎた日も「空いてる」と出る
  - 画像にする月が、空き状況で見ている月ではなく、カレンダーで見ている月になる
  
  → 直し方：画像は空き状況の判定（手で直した分も含む）をそのまま使い、「○ 終日OK／△ 19時〜／灰」の3段で出す。過ぎた日は薄くし、月は空き状況で見ている月にそろえる。「今日から2週間」も選べるようにする。（誰に：社会人全般）
- **1件の予定を相手に送れない**（効き:大・手間:小）— 今：「···」の中に「送る」がない。.ics の書き出しも、全部の予定をまとめて出す形だけ。→ 直し方：「この予定を送る」を足す。「10/3（金）19:00〜 歓迎会 @渋谷」の文・地図のリンク・その1件だけの .ics を、一緒に共有シートへ渡す。点線の予定なら「（まだ仮）」を付ける。設定の書き出しにも「期間／種類／決まった予定だけ」の選択を足す。（誰に：カップル・家族・幹事・会社員）
- **月の予定表を PDF や紙に出せない**（効き:小・手間:中）— 今：作れる画像は「空いてる日」と「給料のまとめ」だけ。→ 直し方：A4 縦に予定名と時刻を並べた表を作る。未定は点線の枠のまま出し、共有シートから印刷もできるようにする。（誰に：子育て中・パート）

#### 予定に持たせる中身
- **Web 会議のリンクを置く欄がなく、メモの中のリンクも押せない**（効き:大・手間:小）— 今：押せるリンクは、場所・レビュー・問い合わせの3つだけ。場所に URL を書くと、地図でその文字を検索するリンクになってしまう。→ 直し方：「＋」に「リンク」を足し、詳細画面に大きく「参加する」ボタンを出す。メモと場所の中の URL と電話番号は、自動で押せるようにする。お知らせの通知からも開けるようにする。（誰に：在宅勤務やオンライン会議の多い人）
- **写真を予定に付けられない**（効き:中・手間:中）— 今：付けられるのは題名・場所・メモなどの文字だけ。→ 直し方：「＋」に「写真」を足す（招待状・学校のお便り・予約確認など）。写真は端末の中に保存し、控えにも入れる。（誰に：子育て中・結婚式に呼ばれることの多い年代）
- **時刻つきで何日にもまたがる予定（出張・旅行）を作れない**（効き:中・手間:中）— 今：時刻つきの予定は翌日までしか伸ばせない。何日も続けられるのは終日の予定だけ。→ 直し方：「終了」の行で日付も選べるようにし、始まりから終わりまで1本の帯で出す。空き状況では、その間の日を×にする。（誰に：出張・旅行・帰省がある人）
- **移動時間を置けず、空き状況にも入らない**（効き:中・手間:中）— 今：予定の開始から終了までしか、ふさがっていると数えない。→ 直し方：「前後の移動（15分・30分・1時間・自分で入れる）」を足し、日の一覧と空き状況ではふさがっている扱いにする。お知らせを「出発の◯分前」にもできるようにする。（誰に：外回りの営業・送り迎えのある人）
- **家族の「誰の」予定かを分けられない**（効き:中・手間:大）— 今：色は種類で決まり、人を入れる欄がない。→ 直し方：種類とは別に「誰の（自分・パートナー・子ども）」を持たせる。帯の左端に頭文字の小さな丸を出し、人ごとに絞り込めるようにする。（誰に：子育て中・共働き）
- **予定に「誰と」を残せず、人ごとにたどれない**（効き:小・手間:中）— 今：「これまでの◯◯」は、題名が同じ予定しか数えない。→ 直し方：「相手（人や会社）」の短い欄を足し、詳細画面に「田中さんとの予定 今年N回・前回◯月◯日」を出す。iPhone の連絡先は読まず、入れた言葉だけでまとめる。（誰に：営業・フリーランス・管理職）
- **「済んだ」の印を付けられるのがバイトだけ**（効き:中・手間:小）— 今：✓にできるのは、バイトの「働いた記録をつける」だけ。→ 直し方：どの予定にも「済んだ」ボタンを置く。日が過ぎても済んでいない用事は、翌日の一覧の上に「まだ済んでいない 2件」と出す。（誰に：振込や書類提出などの手続きを担う人）

#### くり返し
- **くり返しの決め方が足りない**（効き:大・手間:中）— 今：選べるのは毎日・毎週（曜日を選べる）・毎月の同じ日・毎年だけ。期間も、毎週は最長1年、毎月は最長2年、合計200件まで。→ 直し方：「2週ごと」「毎月 第◯◯曜日（複数選べる）」「月末」「平日（月〜金）」「◯か月おき」を足す。「いつまで」には、日付・回数・「ずっと」を選べるようにする（「ずっと」は1年先まで置いておき、近づいたら自動で足す）。（誰に：定例会議・ゴミの日・習い事・通院がある人）
- **くり返しを「これ以降すべて」まとめて直せない**（効き:大・手間:中）— 今：編集はいつも1件だけに効く。くり返しの仲間の印は、消すときにしか使っていない。→ 直し方：保存するときに「この予定だけ／これ以降すべて」を聞く。（誰に：定例会議のある会社員）
- **誕生日・記念日を「ずっと」くり返せず、年齢も出ない**（効き:中・手間:中）— 今：毎年のくり返しは3年か5年まで。iPhone の誕生日カレンダーは取り込まない。→ 直し方：毎年に「ずっと」を足す。生まれた年を入れれば「62歳」「3年目」と出す。取り込みに「誕生日も入れる」を足す。（誰に：家族の行事を管理する人）
- **「月末」や「土日祝なら前後の平日にずらす」支払い日を置けない**（効き:中・手間:小）— 今：毎月31日を選ぶと、31日がない月には置かれない。→ 直し方：「月末」と「土日祝なら前の平日／次の平日にずらす」を足す。祝日は holidays.js の計算をそのまま使える。（誰に：家賃やカードの引き落としを管理する一人暮らしの会社員）

#### お知らせ
- **お知らせが1件に1つだけで、選べる時間も少ない**（効き:中・手間:中）— 今：5分前・15分前・2週間前・1か月前・日時を指定、がない。終日の予定は朝9時で固定。→ 直し方：1件に2つまで付けられるようにする（前日＋30分前、1か月前＋前日など）。選べる時間を増やし、終日のお知らせの時刻は設定で選べるようにする（7:00／12:00／前の晩の21:00）。（誰に：会社員・シフト勤務・車検や免許の更新がある人）
- **通知の本文に場所がなく、未定の予定も同じ文面で鳴る**（効き:中・手間:小）— 今：本文は題名と「10分後 14:00–15:00」だけ。押すと、その日の一覧が開く。→ 直し方：本文を「14:00–15:00・本社3F 会議室A」とし、未定の予定には「（まだ）」を付ける。押したら、その予定の詳細を開く。（誰に：会社員）

#### まとめ・記録
- **有給の残りを数えられない**（効き:中・手間:中）— 今：日数などを数える機能が付いているのはバイトだけ。→ 直し方：「休み」の種類に「有給・半休・特別休暇」を持たせる。今年もらった日数ともらう日を入れておけば「有給 あと7.5日」と出す。点線で入れた休みは別に数え、「全部取るとあと5日」も出す。パートの人には勤務先ごとに持たせる。（誰に：会社員・パート）
- **働いた時間の記録がバイトの種類にしか付かず、残業の合計も出ない**（効き:中・手間:中）— 今：予定の終わりと実際の終わりは両方記録しているが、延びた時間を足し合わせて見せる場所がない。→ 直し方：どの種類にも「働いた時間を記録する」を付けられるようにする。「仕事」に定時を持たせれば「今月の残業 12時間」、シフト勤務なら「予定より延びた時間 6時間15分（8回）」と出す。（誰に：残業の多い会社員・副業をしている人・看護や介護の仕事をしている人）
- **まとめとまとめカードが給料中心**（効き:中・手間:中）— 今：まとめカードはバイトの記録だけから作るので、給料のない人には ¥0 のカードになる。先月との比べもない。→ 直し方：給料のない人には「9月の時間の使い方」カードを出す（仕事120時間・家族18時間・ジム6回・決まった予定32件・流れた予定3件。金額は入れない）。「仕事／自分／家族」の割合の帯と、先月との差も出す。（誰に：会社員・フリーランス）
- **「月に8回ジム」のような目標がない**（効き:中・手間:中）— 今：時間と件数が出るだけ。→ 直し方：種類か予定の名前に「月に◯回／◯時間」の目標を付け、まとめに「ジム 6/8回」と出す。まとめカードにも載せる。（誰に：自分の時間を大事にしたい20〜30代）
- **まとめの内訳が上位3つまでしか出ない**（効き:小・手間:小）— 今：4つ目からは見られない。→ 直し方：「ほか N 件 ›」を置き、押すと全部の名前と時間を並べる。（誰に：案件をいくつも持つフリーランス・副業をしている人）
- **まとめが1月始まりだけで、年度（4月始まり）で見られない**（効き:小・手間:小）— 今：年の数え方は1〜12月だけ。→ 直し方：設定に「年の区切り（1月・4月・自分で選ぶ）」を置く。給料の年の合計は、扶養の計算に合わせて1月始まりのまま残す。（誰に：会社員・教員・公務員）

#### シフト勤務と給料
- **シフトの型を登録して、マスを押すだけで置く入力（スタンプ入力）がない**（効き:大・手間:中）— 今（一部ある）：前に作ったシフトを「···→コピー」し、「複数日」でまとめて置くことはできる（実績と「無くなった」予定からはコピーできない）。足りないのは、名前つきの型の一覧・記号・いつもの休憩・マスを押すだけで置ける入力。→ 直し方：勤務先ごとに、記号1文字・名前・開始と終了（翌日に終わってもよい）・休憩を持つ「型」を作れるようにする。月表示に「シフト入力」を置き、下に並んだ型の札を選んでマスを次々に押せば置けるようにする。「決まってる／希望（点線）」の切り替えも付ける。最初から「日勤 8:30–17:30」「夜勤 16:30–翌9:00」「休」の見本を入れておく。（誰に：看護・介護・飲食や小売のパート）
- **交代勤務の「何日周期」のくり返しが作れない**（効き:中・手間:中）— 今：くり返しは毎日・毎週・毎月・毎年だけ。→ 直し方：型を「日→日→夜→明→休→休」のように並べ、始める日と期間を選べば、その並びをくり返して置けるようにする。「この日から先を作り直す」も用意する。（誰に：交代勤務の看護師・工場・警備・消防）
- **勤務表（写真や LINE の文）からまとめて入れられない**（効き:大・手間:大）— 今：取り込めるのは、iPhone のカレンダーと .ics ファイルだけ。→ 直し方：まず「文を貼って入れる」を作る。「10/1 17-22」「1 休 2 早 3 遅」のような文を読み取り、確認の一覧を見せてから置く。iPhone の文字認識で写真から文字をコピーする使い方も案内する。次の段階で、写真から端末の中だけで読み取れるようにする。（誰に：看護・介護・パート）
- **「休み」を置くと、空いていない扱いになる**（効き:大・手間:中）— 今：確定した終日の予定は、空き状況で×、画像で灰色になる。→ 直し方：最初の種類に「休み」（公休・有休・希望休）を入れる。空き状況では○、画像では空いてる日、まとめの時間には数えない。希望休は点線で置き、勤務表が出たら「通った／通らなかった」を選べるようにする。自分で作った種類にも「空きとして数える」を付けられるようにする。（誰に：看護・介護・パート）
- **夜勤明けの日が「まるごと空いている」扱いになる**（効き:大・手間:中）— 今：日をまたぐ予定は、始まった日にしか出ない。翌日にかかる分は、ふさがっていると数えない。→ 直し方：翌日のマスに、薄い続きの帯か「明」の記号を出す。空き状況と画像でも、翌日の分として数える。設定に「明けの日は△にする」を置く。（誰に：夜勤のある看護・介護・工場・警備）
- **24時間勤務（当直）が0時間になる**（効き:中・手間:小）— 今：開始と終了が同じ時刻だと0時間になる。→ 直し方：同じ時刻なら「翌日の同じ時刻まで（24時間）」として扱い、作成画面にもそう表示する。または、終了を「当日／翌日」から選べるようにする。（誰に：警備・消防・宿直のある人）
- **締め日・給料日で給料を数えられない**（効き:大・手間:中）— 今：月の1日から月末までで数えている。→ 直し方：勤務先ごとに締め日と給料日を持たせ、「10月25日に入る分（9/16〜10/15）¥182,300」のように出す。年の合計は、給料日が入る年で数える。（誰に：パート・派遣・掛け持ちの人）
- **月給・日給・「1回いくら」の手当を入れられない**（効き:中・手間:中）— 今：金額は「（働いた時間−休憩）×時給」だけで出している。→ 直し方：勤務先ごとに「時給／日給／月給」を選べるようにし、型に「夜勤手当 ¥◯◯（1回ごと）」を持たせる。まとめに「手当 夜勤×4 ¥40,000」の行を出す。（誰に：看護・介護・派遣）
- **単発の仕事の時給を入れられない**（効き:中・手間:小）— 今：勤務先を選ばない予定は、「設定の時給」1,120円で計算される。しかも、その時給を変える欄は画面から外されている。→ 直し方：作成画面に「この回だけの時給・交通費」を足し、まとめでは「単発」として1行にまとめる。「設定の時給」はやめるか、画面に戻す。（誰に：スポットワークや副業をする人）
- **時給を上げると、過去の給料まで上がって出る**（効き:大・手間:小）— 今：表示するたびに「今の時給」を掛けて計算している。→ 直し方：働いた記録をつけた時点の時給を、その予定に書き込んでおき、表示はそちらを優先する。時給を変えるときには「◯月◯日以降の記録にだけ効きます」と一言出す。（誰に：パート・扶養の範囲で働く人・掛け持ちの人）
- **辞めたバイト先を残せず、消すと過去の給料が変わる**（効き:中・手間:小）— 今：バイト先を消すと、過去の記録が1,120円で数え直される。→ 直し方：「辞めた（しまう）」を足し、一覧からは消えても過去の記録と時給は残るようにする。消すときは「過去N件の金額が変わります」と確認を出す。（誰に：就職した人・転職した人）
- **夜勤の回数・休みの数・連勤を数えない**（効き:中・手間:中）— 今：まとめに出るのは、種類ごとの時間と件数だけ。→ 直し方：「日勤12・夜勤4・休9」「4週で休み8日」「いちばん長い連勤 6日」を出す。数字を出すだけで、良い悪いは言わない。（誰に：看護・介護）
- **年収の上限を「払われた日」で数えず、このままのペースも出ない**（効き:中・手間:中）— 今：年の給料は働いた日で数えている。上限の表示はまだない（Pro の計画にも1行あるだけ）。→ 直し方：その年に払われる額で数え、「いまのペースだと11月の勤務で超えます」と出す。まだ希望の段階のシフトを入れた場合の見込みは、点線で重ねて見せる。数字について助言しない方針は、そのまま守る。（誰に：扶養の範囲で働くパート）
- **家族に「今月のシフト表」を送れない**（効き:大・手間:中）— 今：シェアできる画像は、「空いてる日」と「給料のまとめ」だけ。→ 直し方：マスに記号と時刻を入れ、下に型の説明を付けた月の画像を作る。載せる種類を選べるようにし、右下に小さく「LUKKO で作成」と入れる。（誰に：子育て中・共働きの看護師やパート）

#### そのほか
- **六曜（大安など）・和暦・週の番号が出ない**（効き:小・手間:中）— 今：祝日だけは、通信なしで計算している。→ 直し方：設定に「六曜を出す」「週の番号を出す」を置く（最初はオフ）。2020〜2040年の表をアプリに持たせ、通信しない。年月えらびと予定の画面には「2026年（令和8年）」と和暦を添える。（誰に：結婚・引っ越しの日取りを決める人、仕事で週番号を使う人）
- **海外出張・旅行の時差を扱えない**（効き:小・手間:大）— 今：時差の考えがない（NEXT.md でも扱わないと決めている）。→ 直し方：まずは出張の予定にだけ「現地時刻」の印を付け、日本時間を小さく添える。日本だけで配信しているので、後回しでよい。（誰に：出張のある会社員）
- **天気が出ない**（効き:小・手間:中）— 今：外に通信しないことを約束している。→ 直し方：入れるなら、オンにした人だけが Apple の天気から取る形にし、送るのは本人が選んだ市区町村だけにする。入れない場合は、ストアで「天気などのためにも通信しません」と、入れない理由を言葉にする。（誰に：外回りの多い人・車で移動する人）

### デザイン
- **月表示のいちばん目立つ所に「給料」スイッチがいつも出ている**（効き:大・手間:小）— 今：バイト先が0件でも、記録が0件でも出ていて、ストアの画像にも写っている。設定の見出しも「バイトと給料」。→ 直し方：バイト先か記録があるときだけ出す。設定に「給料の機能を使う」を置き、オフにしたら見出しのスイッチ・設定の項目・まとめの給料欄をまとめて隠す。空いた場所には「今日」と検索を置く。設定の見出しは「働いた時間と給料」に変える。（誰に：会社員・子育て中）
- **月表示の帯に時刻が出ない**（効き:大・手間:中）— 今：帯には題名だけが、10px の文字で出る。→ 直し方：設定に「帯に開始時刻を出す」を置き、「10 定例」のように時の数字だけを小さく付ける。同じ日の中は時刻の順に並べる。終日は塗りの帯、時刻つきは「色の点＋文字」と見た目を分ける案もある（点線と塗りの違いは、点の形で残す）。（誰に：会社員・営業職）
- **マスに余白があるのに、4段で「+N件」になる。題名も4〜5文字で切れる**（効き:中・手間:中）— 今：1週4段までと決め打ちしている。6.9インチの画面では、各週のマスの下半分が白いまま。→ 直し方：行の実際の高さから入る段数を計算する（大きい画面なら6〜7段）。「+N」を押すとその日の一覧を開く。予定が少ない日は、題名を2行まで折り返す。（誰に：会社員・子育て中）
- **文字が小さく、iPhone の文字の大きさの設定にも合わない**（効き:大・手間:中）— 今：大きさはすべて決め打ちで、帯10px・日付11px・ナビの字10px・空き状況の札10px。指で広げる拡大も止めている。→ 直し方：iPhone の文字の大きさを読み取って、画面全体に反映する。設定にも「標準／大きめ／特大」を置く。大きいときは帯を3段・12px以上にし、いちばん小さい字でも11px以上にする。（誰に：30代以上）
- **ダークモードが iPhone の設定に連動しない**（効き:中・手間:小）— 今（一部ある）：起動画面の色だけは、すでに iPhone の明るい・暗いで変わる（明るいと #FAF9F4、暗いと #1A1A17）。足りないのは次の3つ。
  - アプリ本体は設定のスイッチでしか切り替わらず、最初はオフ。
  - 起動画面の色がアプリの地の色（明るいとき #F6F7F9、暗いとき #0B0D10）とそろっていない。さらに画面が描かれる前の地が #FAF9F4 で固定なので、暗くしている人には一瞬ベージュ、そのあと白が見える。
  - まとめカードとシェアの画面は、いつも暗い地。
  
  → 直し方：「iPhone に合わせる（最初はこれ）／明るい／暗い」の3つから選べるようにする。起動時と描かれる前の地をアプリの地にそろえ、明るい表示のときはカードも明るくする。（誰に：夜に見る人・全員）
- **ウィジェットが暗くならず、字も小さい**（効き:中・手間:中）— 今：地と字は明るい色で固定。iOS 18 の、ホーム画面を1色に染める表示にも合わせていない。字は7〜9pt。→ 直し方：アプリのダークモードと同じ色で暗い組を作る。1色に染める表示では、塗りは面・点線は線で出す。夜の横置き表示（StandBy）でも区別が消えないか、実機で確かめる。字は9pt以上にし、そのぶん段数を減らす。（誰に：全員）
- **今日の印が細い線1本で見つけにくい**（効き:中・手間:小）— 今：マスの上の端に2px の線を引いているだけ。ウィジェットの大サイズは薄い灰色の四角で、印の形がアプリと違う。→ 直し方：今日の日付の数字を、墨色の丸で抜いた形にする。マスの地もごく薄く色を付け、ウィジェットも同じ形にそろえる。（誰に：全員、とくに30代以上）
- **アイコンの代わりに文字の記号を使っていて、ばらばら**（効き:中・手間:小）— 今：「← ‹ › ◀ ▶ ▾ ⌄ ✕ ···」が混ざっている（空き状況だけ ◀ ▶）。設定の行の頭は、四角の中に「↓」「↑」の文字。ナビの「設定」は歯車より太陽に見え、「空き状況」は色付きの文字「○△×」。→ 直し方：線の太さをそろえたアイコン一式に置き換え、「設定」は歯車にする。（誰に：全員）
- **「確定した」ボタンの白い字が読みにくい**（効き:中・手間:小）— 今：種類の色の地に白い字を載せている。バイトの緑や遊びの橙では、読みやすさの目安（字と地の明るさの差が4.5倍）に届かない。→ 直し方：地を種類の色を暗くした色にするか、薄い地に濃い字にする。種類の色を選ぶときに、読みやすいかを自動で確かめる。（誰に：30代以上・屋外で使う人）
- **薄い灰色の文字が読みにくい**（効き:中・手間:小）— 今：曜日の見出しは #9AA0A6、薄い文字には #B3B8C0 を使っている。→ 直し方：14px より小さい文字は、#6B7078 くらいまで濃くする。前後の月の日付だけは、今の薄さのままにする。（誰に：30代以上）
- **種類を色だけで見分けていて、緑と橙が似て見える**（効き:中・手間:小）— 今：最初の4色のうち、緑と橙がほぼ同じ明るさ。赤と緑の見分けがつきにくい人（男性に多いと言われる）には、同じ色に見えるおそれがある。→ 直し方：明るさにも差が出る色の組に選び直す（NEXT.md に残っている B 案と一緒に）。帯に種類の頭文字1文字を出す設定も置く。（誰に：色の見分けがつきにくい人）
- **祝日の名前がほとんど出ず、空き状況では祝日が分からない**（効き:中・手間:小）— 今（一部ある）：祝日の名前は、日の一覧の見出しの下にだけ出る。足りないのは次の3つ。
  - 月表示と作成画面の小さなカレンダーは、数字が赤くなるだけで名前が出ない。
  - 空き状況は祝日を見ていない。土日も、日付が少し薄くなるだけ。
  - 空き状況の行を押しても、何も開かない。
  
  → 直し方：月表示の日付の横に小さく「敬老」と出す。空き状況では日曜と祝日を赤、土曜を青にして、祝日の名前を添える。行を押したら、その日の一覧を開く。（誰に：会社員・子育て中）
- **日の一覧で「何時からどこで」が読みにくい**（効き:中・手間:小）— 今：色の札の中に題名があり、時刻は右端。場所とメモは出ない。→ 直し方：左に開始と終了を縦2段で置き、その右に種類の色の細い縦棒（未定なら点線の棒）を引く。題名は15pxにし、その下に場所を12pxで出す。予定と予定のあいだには「14:00〜16:00 空き」と薄く書く。（誰に：会社員・営業職）
- **ゴミの日や給料日の印が、予定の段を取ってしまう**（効き:中・手間:中）— 今：どの予定も同じ高さの帯になる。→ 直し方：種類ごとに「帯にしないで印だけ出す」を選べるようにし、マスの日付の横に小さな丸や「¥」だけを出す。（誰に：一人暮らし・子育て中）
- **シフトの「早」「夜」がマスで見分けられない**（効き:大・手間:中）— 今：全部同じ緑の「バイト」の帯で、掛け持ちでも色が同じ。→ 直し方：型で置いた予定は、日付の横に記号1文字（14pxくらい）で出す。希望は点線の丸、確定は塗りの丸にし、勤務先の頭文字を小さく添える。（誰に：シフト勤務の社会人・掛け持ちのパート）
- **12か月を1画面で見る年のカレンダーがない**（効き:中・手間:中）— 今：年で見られるのは、まとめの月ごとの棒グラフだけ。年月えらびも月の名前が並ぶだけ。→ 直し方：12か月の小さなカレンダーに、予定の点と祝日を出す。点線の予定は輪で出し、押すとその月へ移る。（誰に：紙の手帳を使ってきた30〜40代・教員）
- **アプリのアイコンが白地で消え、よくある形**（効き:中・手間:小）— 今：白い背景との明るさの差が 1.16 しかなく、ストアの検索結果では輪郭が消える（NEXT.md で見送り中）。綴じ輪の付いたよくある形で、点線の輪は小さい。→ 直し方：絵を大きくし、地を一段濃くする（墨色の地に白い線、など）。「塗りの丸と、大きな点線の輪」に絞る。iOS 18 の暗いアイコンと色付きアイコンも作る。2〜3案を、ストアの「プロダクトページの最適化」（見比べるテスト）で比べる。（誰に：全員）

### 使いやすさ
- **ほかの月から「今日」へ1回で戻れない**（効き:中・手間:小）— 今：年月えらびを開いて「今月」を押す（2タップ）か、何度も横に払うしかない。ナビの「カレンダー」を押し直しても、月は戻らない。→ 直し方：今月以外を見ているときだけ、見出しに「今日」を出す。ナビの「カレンダー」をもう一度押しても今日に戻るようにし、今日のマスを一瞬光らせる。（誰に：全員）
- **開始時刻を動かしても、終了時刻がついてこない**（効き:大・手間:小）— 今：10:00–11:00 の開始を14:00にすると、「14:00〜翌11:00」の21時間の予定になる。画面には「日をまたぐので、終わりは翌日です」の一行が出るだけ。→ 直し方：長さを保ったまま、終了も一緒に動かす。終了の下に「30分・1時間・1時間半・2時間」のボタンを置く。日をまたぐのは、終了をわざと開始より前にしたときだけにする。（誰に：会議の多い会社員）
- **新しい予定の最初の値が、いつも「用事・10:00–11:00」**（効き:中・手間:小）— 今：今の時刻にも、前回使った種類にも関係なく、同じ値で始まる。→ 直し方：今日の予定なら、次の区切りの時刻から始める。種類は前回使ったもの（か、設定で選んだ「いつもの種類」）にする。種類ごとに、いつもの時刻と長さを決められるようにする。（誰に：会社員・フリーランス）
- **お知らせの最初の値がいつも「なし」**（効き:中・手間:小）— 今：予定を作るたびに、お知らせを自分で選ぶ必要がある。→ 直し方：設定に「いつものお知らせ」を置き、時刻つきと終日で別々に決められるようにする。（誰に：会社員・子育て中）
- **未定の予定を押すと、中身より先に「どうなった？」が出る**（効き:大・手間:小）— 今：未定の予定を一覧から押すと必ず小窓が出る。小窓には場所もメモも出ず、見るには編集画面まで行くしかない。→ 直し方：先の日付の未定の予定は、押したら詳細画面を開く。「どうなった？」は、詳細画面の主ボタンから聞く。今日と過去の未定だけ、今までどおり小窓を出す。日の一覧の行にも、場所を1行出す。（誰に：仮の予定が多い会社員・フリーランス）
- **題名欄にすぐ打てず、改行キーで保存できない**（効き:中・手間:小）— 今：画面を開いても、題名欄を1回押さないと打てない。改行キーを押しても何も起きない。→ 直し方：新しく作るときは、題名欄にカーソルがある状態で開く。改行キーを「完了」にして、押したら保存する。（誰に：毎日たくさん入れる人）
- **よく入れる予定を1タップで入れられない**（効き:大・手間:中）— 今（一部ある）：詳細の「···→コピー」を使えば、題名・種類・時刻・場所・メモ・お知らせ・バイト先ごと写せる。ただし手順は5手以上かかり、未定の予定は一覧から押すと小窓が出るので、詳細画面までたどり着きにくい。バイト先を選べば、題名にその名前が入る。足りないのは、題名の候補と、よく使う予定の一覧。→ 直し方：題名欄の下に、ここ3か月で多い題名を5〜6個ボタンで並べる。押すと、種類・時刻・場所・お知らせも前回と同じ内容で入る。打ち始めたら、候補を絞って出す。「＋」を長押しすると「よく使う予定」から選べるようにする。（誰に：通勤中に入れる会社員・子育て中）
- **「明日15時 歯医者」のように1行で入れられない**（効き:中・手間:大）— 今：題名・日付・時刻を、別々に操作する必要がある。→ 直し方：作成画面のいちばん上に「一言で入れる」欄を置く。「10/3 19-21時 飲み会 渋谷」を日付・時刻・題名・場所に分けて入れる。「たぶん」「仮」や、最後に「？」があれば点線で置く。読み取った結果を見せ、直してから保存できるようにする。（誰に：移動中に入れる会社員）
- **時刻が5分きざみのドラムだけで、数字で打てない**（効き:中・手間:小）— 今：分は5分きざみで、表示はいつも24時間。→ 直し方：時刻を押したら「0903」のように数字で打てるようにする。1分きざみも選べるようにし、iPhone が12時間表示なら「午後7:00」と出す。（誰に：電車の時刻や病院の予約を入れる人）
- **保存ボタンが右上にあり、片手では届かない**（効き:中・手間:小）— 今：保存は画面の一番上の右端だけ。→ 直し方：画面の下（キーボードが出ているときはそのすぐ上）に、大きい「保存」をいつも置く。（誰に：電車の中で片手で入れる人）
- **画面の左の端からなぞって戻れない**（効き:中・手間:中）— 今：戻るには、左上の「←」を押すしかない。→ 直し方：左の端から右へなぞると前の画面に戻るようにする。書きかけがあるときは「捨てますか？」と聞く。（誰に：大きい iPhone を使う人）
- **日の一覧で、前の日・次の日へ送れない**（効き:中・手間:小）— 今：見出しは「← 9月24日（水）」だけ。→ 直し方：見出しの左右に「‹ ›」を置き、横に払っても前後の日へ移れるようにする（左に払って消す動きとぶつからないようにする）。（誰に：会社員・子育て中）
- **予定の画面の日付に曜日がなく、月をまたぐとずれる**（効き:中・手間:小）— 今：「いま見ている月」と予定の「日」を組み合わせて日付を作っている。そのため、8/30〜9/2 の予定を9月1日から開くと「9月30日」と出る。→ 直し方：予定そのものの年・月・日から「9月24日（水）」を作る。今年でなければ年も付け、何日も続く予定は「8月30日（日）〜9月2日（水）」と出す。祝日なら名前も添える。（誰に：全員）
- **予定の画面で「編集」が「···」の奥にある**（効き:中・手間:小）— 今：右上には「···」しかない。→ 直し方：右上に「編集」を置き、「···」の中にはコピー・まとめに入れない・削除を残す。（誰に：予定がよく変わる会社員）
- **時間が重なっても知らせない**（効き:中・手間:小）— 今：保存のときに、ほかの予定との重なりを調べていない。→ 直し方：作成画面の時刻の下に「この時間は『定例会議』と重なっています」と出す（確定と未定を分けて書く）。止めずに知らせるだけにする。（誰に：会社員・フリーランス）
- **長押ししても何もできない**（効き:中・手間:中）— 今：マスにも、一覧の行にも、長押しの動きがない。→ 直し方：マスを長押ししたら、その日の新しい予定の画面を開く。行を長押ししたら「確定した・日にちを変える・コピー・編集・削除」を出し、軽い振動も付ける。（誰に：全員）
- **予定を指で別の日へ動かせない**（効き:中・手間:大）— 今：月表示の帯は、押しても反応しない作り。→ 直し方：帯を長押しで持ち上げて別のマスへ動かせるようにし、動かしたあとに「9/24 → 9/26 に動かしました 元に戻す」を出す。（誰に：予定がよく動く会社員）
- **種類を消す・隠す・並べ替えることができず、呼び名も変えられない**（効き:中・手間:中）— 今：できるのは、足すことと、名前と色を変えることだけ。最初の4つの種類は、名前を変えても「希望シフト」「約束、決まった？」の呼び名が残る。→ 直し方：「隠す（予定は残す）」と「消す（予定を別の種類へ移す）」を足し、指で並べ替えられるようにする。先頭の種類を、新しい予定の最初の種類にする。種類ごとに「まだのとき／決まったとき」の呼び名を変えられるようにする。（誰に：バイトをしていない社会人）
- **予定をまとめて選んで、消したり種類を変えたりできない**（効き:中・手間:中）— 今：1件ずつしかできない（くり返しの「この日から先も消す」と、取り込みの整理だけは例外）。→ 直し方：「選ぶ」でチェックを付け、「消す／種類を変える／まとめに入れない」をまとめてできるようにする。（誰に：取り込みを使った人・異動や退職した人）
- **押しても反応しない所や、戻る先がずれる所がある**（効き:小・手間:小）— 今：次の3つ。
  - 前後の月の薄い日付は、押しても何も起きない。
  - 予定を編集して保存すると、どこから開いても月表示に戻る。
  - 取り込みの「←」「やめる」は、どこから来ても設定に戻る。
  
  → 直し方：薄い日付を押したらその月のその日を開く。保存したあとは、開く前の画面に戻す。取り込みは、来た画面に戻す。（誰に：全員、とくに初めて使う人）
- **しばらくして開くと、前の画面のままで、「今日」も昨日のまま**（効き:中・手間:小）— 今：アプリに戻ってきたときにやっているのは、取り込みの続きと保存だけ。日付が変わったかどうかは、1分ごとにしか確かめていない。→ 直し方：戻った瞬間に今日を確かめ直し、ウィジェットとお知らせも作り直す。30分以上たっていたら、月表示の今月に戻す。（誰に：朝に今日を見る人）
- **勤務表が出たとき、その月の希望をまとめて確定できない**（効き:大・手間:小）— 今：1件ずつ3タップかかり、20件なら20回くり返す。→ 直し方：未定がある月だけ「この月のまだ N 件を見直す」を出す。チェック付きの一覧で「ぜんぶ確定」「チェックしたものを無くなった」を押せるようにし、時刻がずれた日だけその場で直せるようにする。（誰に：パート・看護師）
- **過ぎたシフトの記録がたまっていく**（効き:中・手間:小）— 今：1件ずつ「働いた記録をつける」を押す必要があり（最短4タップ）、ベルにも1件ずつたまる。→ 直し方：ベルに「予定どおりでまとめて記録」を置く。勤務先ごとに「終わったら予定どおり記録したことにする」を選べるようにし、シフト後のリマインドのオン・オフも勤務先ごとにする。（誰に：フルタイムのパート）
- **休憩の選択肢が90分までで、毎回選ぶ**（効き:中・手間:小）— 今：「なし〜90分」の6つだけ。→ 直し方：120分と、自由に打てる欄を足す。勤務先か型に「いつもの休憩」を持たせる。（誰に：夜勤のある人・フルタイムのパート）
- **読み上げ機能（VoiceOver）でカレンダーが読めない**（効き:中・手間:中）— 今：マスに読み上げ用の名前がなく、点線かどうかも読み上げでは分からない。ナビの項目にも、ボタンだという印がない。→ 直し方：マスを「9月24日 木曜日、予定2件、うち未定1件」と読むようにし、ナビの項目にも名前を付ける。（誰に：読み上げを使う人）

### 安心・データ
- **自分の iCloud を使った同期がない（iPad や2台目の iPhone で見られない）**（効き:大・手間:大）— 今：同期はない。アプリは iPhone 専用で、コードには「将来の同期のため」の更新時刻が入っているだけ。pro-plan.md には「同期は別の製品の話」とある。→ 直し方：Apple が用意している、本人専用の iCloud の置き場を使う。開発者は中身を見られず、アカウント登録も要らない。設定に「iCloud で同期」（最初はオフ）を置く。同じ予定なら新しいほうを残し、消した予定には「消した」印を残してほかの端末にも伝える。まず iPhone 2台のあいだで、次に iPad へ。（誰に：2台持ちの人・iPad や Mac も使う会社員）
- **自動の控えがない**（効き:大・手間:小）— 今：保存は1つのファイルを毎回上書きしているだけで、控えは手で書き出すしかない。→ 直し方：1日1回、端末の中に日付つきの控えを書く。7日分と、毎月1日の分を3か月残す。設定の一覧から選んで戻せるようにする。大きさは予定200件でも数十KB ほど（App.jsx の説明）。（誰に：全員）
- **控えが端末の外に自動で置かれず、ファイルアプリからも見えない**（効き:大・手間:中）— 今：控えは共有シートに渡すだけ。→ 直し方：iCloud Drive の「LUKKO」フォルダへ週1回自動で置き、新しい5つだけ残す。ファイルアプリの「この iPhone 内」にも LUKKO フォルダが見えるようにする。新しい iPhone で開いたときに iCloud Drive に控えがあれば、「前の iPhone の予定を戻しますか？」と聞く。（誰に：会社員・子育て中）
- **最後に控えを取った日も、保存がうまくいっているかも見えない**（効き:中・手間:小）— 今：設定には「ときどき控えを取って」の文があるだけ。→ 直し方：「この iPhone に保存済み 予定312件・さっき」「最後の控え：8月30日／まだ取っていません」を出す。30日を超えたら、ベルに1件だけ知らせる。（誰に：全員）
- **機種変更のしかたを書いていない**（効き:大・手間:小）— 今：保存先は iPhone の iCloud バックアップに入る場所を選んでいるので、iPhone ごと移せば予定も移る作りのはず。でも利用者向けには「ときどき控えを」としか書いていない。→ 直し方：まず実機で、クイックスタートと iCloud バックアップからの復元の両方を確かめる。そのうえで、設定・ストア・サポートページに「①ふつうに iPhone を移せば予定も移る ②移らなかったら控えから戻す」の短い図を載せる。（誰に：全員）
- **消した予定を戻せない**（効き:大・手間:中）— 今（一部ある）：「無くなった」にした予定は詳細の「予定として戻す」で、確定した予定は編集の「まだ不確定」で、手で戻せる。足りないのは次の3つ。
  - 削除は「元に戻せません」と出る。
  - 書きかけの予定は、キャンセルを押すと確かめずに閉じる。
  - 1タップで取り消すしくみがない。
  
  → 直し方：消した直後や、確定・無くなったにした直後に、画面の下へ「削除しました 元に戻す」を5秒出す。消した予定は30日間「最近消した予定」に置く。確認の文は「30日間は設定から戻せます」に変える。書きかけでキャンセルを押したら「捨てますか？」と聞く。（誰に：全員）
- **控えから戻す前や、取り込む前に、今の状態を残さない**（効き:中・手間:小）— 今：戻すと中身が丸ごと置き換わる。取り込みは、まとめて取り消せない。→ 直し方：直前に自動で控えを1つ取る。取り込みの完了画面に「取り込む前に戻す」を置き、設定には「最後の取り込みを取り消す（N件）」を残す。（誰に：取り込みから使い始める人）
- **起動したとき、古いほうの保存から始まることがある**（効き:中・手間:小）— 今：保存は2か所にあり、どちらも保存した時刻を持っている。それなのに起動時は、片方（ブラウザ側の保存）に中身があればそれだけを使う。空き容量が足りずにそちらへ書けない日が続くと、古い中身で始まり、次の保存で新しいほうも上書きされてしまう。→ 直し方：起動したら両方の時刻を比べ、新しいほうを使う。食い違っていたら一言知らせ、上書きする前に古いほうを控えに残す。（誰に：空き容量の少ない iPhone の人）
- **まれに真っ白になる原因が、まだ分かっていない**（効き:大・手間:中）— 今（一部ある）：iPhone がアプリの画面を止めたときは、自動で読み直すしくみがある。画面のエラーでは「うまく表示できませんでした」と「もう一度開く」を出し、最後のエラー1件を端末に残している。足りないのは次の3つ。
  - 残したエラーを見る場所も、送る道もない。
  - 画面を止められたこと自体を記録していない。
  - 原因がまだ分かっていない。

### iPhone連携
- **会社や家族のカレンダーを「重ねて見る」しくみがない**（効き:大・手間:大）— 今：取り込みは1回写すだけで、あとから元が変わっても追いかけない。→ 直し方：取り込みとは別に「iPhone のカレンダーを重ねて表示」を作る。選んだカレンダーを開くたびに読み直し、細い灰色の帯で並べる。LUKKO には保存せず、直すのは元のアプリで行う。空き状況の判定にも入れる。許可は今と同じ「読むだけ」で済む。（誰に：Outlook や Google に会議が入る会社員・家族のカレンダーがある人）
- **決まった予定を iPhone のカレンダーへ入れられない**（効き:大・手間:中）— 今：「読むだけ・書き込まない」を約束している（許可の説明文、規約、設定の文）。ただし今の iPhone では、読むだけでも「すべての操作」の許可をもらっている。使っている部品にも、予定を作る・直す機能がある。→ 直し方：設定に「決まった予定を iPhone のカレンダーにも入れる」を置く（最初はオフ）。「LUKKO」という名前のカレンダーを1つ作り、そこにだけ書く（書く先を選べてもよい）。未定の予定は入れないか、「(仮)」を付けて入れる。LUKKO で直したり消したりしたら、向こうも同じように直す。題名を「私用」に置き換えて書く選択肢も付ける。説明の文は同じ版で書き換える。（誰に：Apple Watch・Mac・会社のカレンダーでも予定を見る人）
- **取り込み直すと予定が二重になる**（効き:大・手間:中）— 今：元の予定の番号は読んでいるのに、保存のときに捨てている。同じ予定かどうかは「日・開始時刻・題名」だけで見分けている。そのため、元で時刻を変えると新旧の2件が残り、元で消えた予定も残り続ける。.ics の番号も残していない。→ 直し方：元の番号を残す。2回目からは「変わった3件／元で消えた1件／新しい5件」に分けて見せ、上書きするか残すかを選べるようにする。（誰に：会社のカレンダーを取り込む会社員）
- **取り込むと場所・メモ・URL・日数が落ち、日をまたぐ予定が23:59で切れる**（効き:中・手間:小）— 今：写すのは題名と時刻だけ。何日も続く終日の予定は1日分になり、夜勤のような日またぎの予定は23:59で切れる（LUKKO 自身が書き出した夜勤でも同じ）。受け取る側の作りは、すでにある。→ 直し方：場所・メモ・URL・日数も写し、日またぎの予定は翌日の時刻のまま持つ。完了画面に「場所つき12件、何日も続く予定3件」と出す。（誰に：会社員・出張や夜勤のある人）
- **取り込むカレンダーを選べず、種類にも結びつけられない**（効き:大・手間:中）— 今：購読と誕生日のカレンダー以外を全部読み、元のカレンダー名も取っていない。先月から12か月分を、1件ずつ並べる。→ 直し方：最初に、iPhone にあるカレンダーの一覧（名前・色・件数）をチェック付きで出す。カレンダーごとに種類を決められるようにし（例：会社の予定表 → 仕事）、選んだ内容を覚えておく。一覧は月ごとの見出しで区切る。（誰に：会社員・子育て中）
- **取り込むと仕事の予定が「バイト」になる**（効き:大・手間:小）— 今（一部ある）：会議・打ち合わせ・MTG・面談・面接は、すでに「用事」に当たる。自分で「仕事」という種類を作れば、題名に「仕事」を含む予定はそこに当たる。足りないのは次の4つ。
  - 最初から「仕事」の種類がない。
  - 「勤務・出勤・日勤・夜勤」を含む予定と、「同じ名前・同じ時間帯が3回以上あって3時間以上」の予定がバイトになる。そのため毎週の長い研修や「在宅勤務 9:00–18:00」もバイト扱いになる。
  - パート・準夜・当直・宿直・公休・有休・明け、は当てる言葉にない。
  - 日をまたぐ予定は長さの計算がマイナスになり、当たらない。
  
  → 直し方：会社員やシフト勤務を選んだ人には、最初から「仕事（勤務）」の種類を入れる。勤務・出勤・業務・商談・来客・出張・定例・1on1・研修・在宅・残業はそこに当てる。バイトをしない人には、くり返しからバイトと決める判定を外す。休・公休・有休・明けは「休み」に当てる。同じ1文字の題名が3回以上あれば、「シフトの型にしますか？」と聞く。（誰に：会社員・看護師・介護職）
- **取り込めるのが先月からで、過去の記録を持ってこられない**（効き:小・手間:小）— 今：読む範囲は、先月の頭から12か月先まで。→ 直し方：「今年のはじめから／1年前から」も選べるようにし、過去の分をまとめに入れるかどうかも選べるようにする。（誰に：ほかのカレンダーから乗り換える人）
- **メールで届いた .ics や控えを押しても、LUKKO で開けない**（効き:中・手間:中）— 今：「このアプリで開けるファイル」の登録がない（NEXT.md にも残っている）。→ 直し方：.ics と控えを登録する。開いたら、.ics なら取り込みの一覧（仮で入れる／確定で入れる）へ、控えなら「控えから戻す」の確認へ進む。（誰に：会社員）

- **ウィジェットを押しても、その日やその予定に飛ばない**（効き:中・手間:中）— 今：押したときの行き先が決まっておらず、アプリにも外から特定の画面を開く入口がない。→ 直し方：アプリ専用の開き方（例：lukko://day/2026-09-28）を作る。小サイズは今日、中サイズの行はその予定、「まだ N 件」は未定の一覧、大サイズのマスはその日を開く。アイコンの長押しメニューや通知も、同じ入口を使う。（誰に：ウィジェットを使う人）

- **ウィジェットの上で「決まった」を押せない**（効き:中・手間:大）— 今：ウィジェットにボタンがない（iOS 17 以上なので、置くしくみ自体は使える）。→ 直し方：中・大サイズに「まだ決まっていない次の予定」と「決まった」「無くなった」のボタンを出す。押した結果はアプリとの共有の場所に書いておき、次にアプリを開いたときに反映する。（誰に：候補日を持っている会社員）
- **通知から「決まった」「無くなった」「予定どおり終わった」を押せない**（効き:大・手間:中）— 今：通知にボタンがなく、押すとその日の一覧が開くだけ。→ 直し方：未定の予定の通知には「決まった／無くなった／あとで」、シフト後の通知には「予定どおり（休憩60分）／30分延びた／開いて直す」を付ける。押したら通知の上で終わり、アプリは開かない。このボタンは無料にする（毎日使う理由になるため）。（誰に：会社員・シフト勤務）
- **集中モード中に、会議直前のお知らせが届かない**（効き:中・手間:中）— 今：通知はすべてふつうの強さで、集中モード中でも通す「時間指定の通知」の許可をもらっていない。→ 直し方：許可をもらい、10分〜1時間前のお知らせは集中モード中でも届くようにする。設定でオン・オフできるようにする。（誰に：会議の多い会社員）
- **集中モードに合わせて、見せる予定を切り替えられない**（効き:小・手間:大）— 今：集中モードとつながるしくみがない。→ 直し方：iPhone の集中モードの設定に LUKKO を出し、「仕事」のときは仕事の予定だけ見せる、のように切り替えられるようにする。（誰に：仕事と私用を分けたい人）
- **Siri やショートカットから予定を足せない**（効き:中・手間:大）— 今：呼び出せる操作がない。→ 直し方：「予定を足す（決まってる／まだ）」「今日の予定」「まだ決まっていない予定」「この日は空いてる？」の4つを用意する。（誰に：車で通勤する人・手がふさがりがちな子育て中の人）
- **メールや LINE の文から予定を作れない**（効き:大・手間:大）— 今：予定はアプリの中の「＋」からしか作れない。→ 直し方：共有シートから文を受け取り、日付・時刻・場所を拾って「まだ」の予定の下書きを作る。スクリーンショットからも作れるようにする。（誰に：幹事役・打ち合わせを調整する人）
- **アイコンを長押ししたときのメニューがない**（効き:小・手間:小）— 今：何も出ない。→ 直し方：「予定を追加」「まだ決まっていない予定」「空いてる日をシェア」「今日」を出す。（誰に：全員）
- **コントロールセンターやアクションボタンから足せない**（効き:小・手間:中）— 今：置ける操作がない。→ 直し方：「予定を追加（まだ）」と「今日の予定」を置けるようにする（iOS 18 から使える）。（誰に：新しい iPhone を使う人）
- **iPhone の検索で予定が出てこない**（効き:小・手間:中）— 今：iPhone 全体の検索に予定を登録していない。→ 直し方：題名・日付・場所を、端末の中だけの検索に登録する（外には送られない）。「検索に出さない」も選べるようにする。（誰に：予定の多い人）
- **会議やシフトの残り時間を、ロック画面や画面上部に出せない**（効き:小・手間:大）— 今：出し続ける表示がない。→ 直し方：「14:00–15:00 定例 残り23分／次 15:30 来客」を出し続ける表示（ライブアクティビティ）を作る。（誰に：会議が続く人・長時間のシフト）

- **iPad と Mac に合わせた画面がない**（効き:中・手間:中）— 今（一部ある）：iPhone 版は、iPad でも iPhone の大きさのまま動く。Mac でも、App Store Connect の最初の設定のままなら使えている可能性がある（オフにしたかどうかは未確認）。足りないのは、同期がないので iPhone の予定を見られないこと。→ 直し方：まず App Store Connect で Mac の設定を確かめる。iPad は、今の画面の板を中央に置く作りを生かす。iCloud 同期と一緒に進める。（誰に：Mac で仕事をする人・iPad を持っている人）

### 見せ方・ストア
- **ストアの画像と見本の予定が、学生の暮らし**（効き:大・手間:中）— 今：次のとおり。
  - 登録している最初の3枚すべてに「バイト」が写っている。1枚目の札の先頭は「✓ バイト」、2枚目はバイトの帯が9本、3枚目は「このシフト、どうなりました？」。
  - 見本（demo.js）の22件のうち10件がバイトで、仕事の予定は0件。バイト先を作っていないので、まとめカードに「バイト先なし」と出る。

- **設定に「.ics」など分かりにくい言葉が出ている**（効き:小・手間:小）— 今：「ファイルから取り込む（.ics）」「予定をファイルに書き出す（.ics）」と書いてあり、「控え」との違いも説明されていない。→ 直し方：「TimeTree・Google から移す（ファイル）」「ほかのカレンダー用に書き出す」「機種変更用に保存する（控え）」のように、目的で書く。「.ics」は小さな補足に下げ、アプリごとの書き出し方を図で案内する。（誰に：スマホに慣れていない人・乗り換えてくる人）

### 最初の体験・続けてもらう
- **最初に「どんな使い方？」を聞かない**（効き:大・手間:中）— 今：案内の4枚は、しくみ・空き状況・シェア・取り込みの説明だけ。誰が入れても、同じ種類（用事・バイト・遊び・その他）・同じ給料スイッチ・同じ週のはじまりで始まる。→ 直し方：「ふだんの予定に近いのは？」を1問だけ聞く（学校とバイト／会社の仕事／シフト勤務（看護・介護・販売など）／フリーランス・副業／子育て・家族）。答えで次のものを決める。
  - 最初の種類（会社：仕事・プライベート・家族・その他／子育て：仕事・子ども・家族・自分／シフト：勤務・休み など）
  - 呼び名と見本と入力例
  - 給料の表示
  - 空き状況で見る時間帯
  - 週のはじまり
  - シフトの型の見本
  
  あとから設定で変えられるようにする。（誰に：社会人全般）
- **案内1枚目の見本が「カフェバイト」で、問いは「用事」**（効き:中・手間:小）— 今：見本は、点線の「？カフェバイト」と塗りの「映画」。問いは「この用事、どうなりました？」で、見本と食い違っている。日付も7月25日（土）で固定。→ 直し方：見本を「？同期と飲み会」「？打ち合わせ」と塗りの「歯医者」にし、問いを見本に合わせる。日付は今週の実際の日にする。答えた使い方で見本を替える。（誰に：会社員・20代後半以上）
- **案内の1枚目で待たされる**（効き:中・手間:小）— 今（一部ある）：2〜4枚目は、演出の途中でも「つぎへ」を押せる。右上の「スキップ」もあり、iPhone で「視差効果を減らす」にしている人には待ち時間がない。待たされるのは1枚目で、点線の見本が約2.1秒後に出るまで押すものがない。演出だけを飛ばすしくみもない。→ 直し方：画面をタップしたら演出を飛ばす。待ち時間は1秒以内にし、2回目からは最初から全部出す。1枚目は押さなくても「次へ」で進めるようにする。2・3枚目を1枚にまとめ、全部で3枚にする。（誰に：忙しい社会人）
- **案内で「会社の予定を入れても外に出ない」と言っていない**（効き:中・手間:小）— 今（一部ある）：「外部へ送らない」は、取り込みの許可を聞く iPhone の小窓の説明文にだけ書いてある。案内の4枚目は「読むだけです。書き込みはしません」だけ。→ 直し方：案内の4枚目と取り込みの最初の画面に、「アカウント不要。予定はこの iPhone の中だけで、どこにも送りません」と足す。（誰に：仕事の予定を扱う会社員）
- **取り込んだ予定が全部「決まってる」になり、点線を一度も見ない**（効き:大・手間:中）— 今（一部ある）：.ics で「仮」になっている予定だけは、点線で入る。足りないのは次の3つ。
  - iPhone のカレンダーから取り込んだ分は、全部「決まってる」になる。
  - 一覧で状態を変えられない。
  - 完了画面は「すべて『決まってる』として置きました」と出る。
  
  → 直し方：題名に「仮」「(仮)」「候補」「未定」「調整中」「？」「TBD」があれば点線にする。iPhone 側で仮になっている予定も、読み取れるなら点線にする。一覧の各行に「決まってる／まだ」の切り替えを付ける。取り込んだあとに「この先2週間で、まだ決まっていない予定は？」の1画面を挟む。（誰に：今のカレンダーから乗り換える人）
- **空の月表示の案内が「＋から置いてみて」だけ**（効き:中・手間:小）— 今：「＋」で作ると最初は「決まってる」になっているので、最初の1件がふつうの塗りの予定になる。→ 直し方：「？まだ決まっていない飲み会」「歯医者の予約」「？出張（仮）」の例のボタンを置く。押すと、題名が入って「まだ不確定」が選ばれた状態で作成画面が開くようにする。（誰に：初めて使う20代以上）
- **見本の予定で試す道がない**（効き:中・手間:小）— 今：demo.js の見本は、?demo=1 を付けたときだけ入る撮影用。→ 直し方：案内の最後と空の案内に「見本の予定で試してみる」を置く（中身は社会人にも合うもの）。見本を出している間は上に「見本を表示中｜消す」の帯を出し、1タップで消せるようにする。（誰に：様子見で入れた人・会社の予定を入れたくない人）
- **朝（か前の晩）に、予定をまとめて知らせる通知がない**（効き:大・手間:小）— 今：通知は、予定ごとのお知らせと、シフト後の「実働どうだった？」の2つだけ。→ 直し方：設定に「朝のまとめ（例 7:30）」「前の晩のまとめ（例 21:00）」を置く。
  - 文面の例：「今日 3件（仮押さえ1）：10:00 定例、14:00 ◯◯社、19:00 飲み会？」
  - シフト勤務の人には「明日 早番 7:00–16:00（〇〇病院）」、休みの前の晩に「明日は休み」も選べる。
  - 予定が0件の日は送らない。「平日だけ／毎日」も選べる。
  - 1週間分を前もって予約しておく（通知を予約できる数の上限60件の中で）。
  - 案内の最後に「毎朝お知らせしますか？」と聞いてから、通知の許可を求める。
  
  （誰に：通勤する会社員・朝の早い人）
- **未定の予定を、週に1回まとめて片づける場がない**（効き:大・手間:中）— 今：未定は1件ずつ押すしかなく、ウィジェットの「まだ N 件」から一覧にも行けない。→ 直し方：日曜の夜（時刻は選べる）に「来週、まだ決まっていない予定が3件」と知らせる。開くとカードが並び、それぞれ「決まった／無くなった／まだ」を選べる。全部片づいたら「来週の予定、ぜんぶ決まりました」と出す。Pro の期限とは別の、無料の中心の流れにする。（誰に：会社員・幹事役）
- **日が過ぎても点線のままの予定に、何も聞かない**（効き:中・手間:小）— 今：ベルに入るのは、記録していないシフトとアップデートだけ。→ 直し方：「昨日の『歓迎会？』どうなりました？」をベルに入れ、その場で選べるようにする。前の晩に「明日の『◯◯？』はまだ決まっていません」と知らせることも選べるようにする。（誰に：会社員・子育て中）
- **くり返しが切れる前に「延ばしますか？」と聞かない**（効き:中・手間:小）— 今：毎日のくり返しは半年、毎週は1年で、黙って終わる。→ 直し方：最後の回の2週間前に、お知らせと通知で聞く。押したら、同じ決まりで先を足す。（誰に：通院・習い事・定例がある人）
- **新しく入れた人に、ウィジェットを知らせていない**（効き:中・手間:小）— 今：ウィジェットを知らせたのは、0.26.0 のアップデートのお知らせだけ（初めて開いた人には出ない）。→ 直し方：予定が5件を超えたときか、使い始めて3日目に、ベルで1回だけ知らせる。「長押し → ＋ → LUKKO」の3コマの絵を付け、設定にも「ウィジェットの置き方」を置く。（誰に：全員）
- **月の初めに、先月をふり返るきっかけがない**（効き:中・手間:小）— 今：まとめは、自分で開かないと見られない。→ 直し方：毎月1日の朝、希望した人にだけ「9月は 仕事62時間・ジム6回・飲み会3回でした」と知らせ、押すと先月のまとめを開く。（誰に：時間の使い方を見直したい人）
- **使い方をもう一度見る場所と、よくある質問がない**（効き:中・手間:小）— 今：案内は一度終えると、二度と見られない。→ 直し方：「このアプリについて」に「使い方をもう一度見る」と「よくある質問」を置く。質問の例は「Google カレンダーと同期できる？」「機種変更のときは？」「会社の予定は外に出る？」「iPhone のカレンダーに書き込む？」。（誰に：慎重に選ぶ30代以上）
- **使いはじめの人の声を聞く入口がない**（効き:中・手間:小）— 今：使われ方の情報を集めない方針なので、やめた理由を知る手段がない。→ 直し方：使い始めて7日目に1回だけ、ベルに「1週間使ってみてどうでしたか？」と入れる。押すと、件名入りのメールが開く。星の小窓とは時期をずらす。（誰に：様子見で入れた社会人）
- **卒業・就職で、使い方を切り替える道がない**（効き:大・手間:中）— 今：種類を消すことも、過去の予定を移すこともできない。給料の表示は、バイトを辞めても出続ける。3〜4月に何かを知らせるしくみもない。→ 直し方：設定に「働き方が変わった」を置き、1画面で次の3つを選べるようにする。
  - 「仕事」の種類を足して、新しい予定の最初の種類にする
  - バイト先をまとめて「辞めた」にする
  - 給料の表示を隠す
  
  3月末〜4月に一度だけ「4月から社会人の方へ」と知らせる。今使っている学生が、就職しても乗り換えずに使い続けられるようにするための入口です。（誰に：新社会人）

## 4. 「LUKKO だけの強み」を社会人向けにどう言い換えるか

1. **点線 → 仮押さえ**
   - 今：「まだ分からない予定は点線」
   - 社会人向け：「会議の仮押さえも、飲み会の候補日も、点線のまま置ける」「仮押さえを、仮押さえのまま置けるカレンダー」
2. **決まる瞬間 → 仮押さえが片づく**
   - 今：「点線が塗りに変わる」
   - 社会人向け：「確定したら塗りに変わる。まだ決まっていないものが一目で分かるから、仮押さえの放っておきがなくなる」
   - 注意：未定の一覧や、週1回の片づけの流れができると、この言い方にもっと力が出ます。
3. **空いてる日だけ送れる → 中身を見せずに日程調整**
   - 社会人向け：「予定の中身を見せずに、空いている日だけを送れる。仕事の相手にも、文字でも」
   - 注意：ていねいな版と、文字でコピーができてから言う。
4. **通信しない・アカウントなし → 会社の予定も外に出ない**
   - 社会人向け：「会社の予定を入れても、外に出ない。アカウント登録なし・広告なし・月額なし」
5. **取り込み（読むだけ）→ 乗り換えなくていい**
   - 社会人向け：「いまのカレンダーはそのまま。元のカレンダーは書き換えません」
   - 注意：「重ねて表示」ができたら「いまのカレンダーはそのまま、仮の予定だけ LUKKO に」と言えます。それまでは「取り込める」までにとどめる。
6. **手帳の感覚 → 鉛筆とペン**
   - 社会人向け：「鉛筆で仮に書いて、決まったらペンで清書。紙の手帳のあの感覚を、iPhone に」（紙の手帳からスマホに移る30〜40代向け）

補足：給料と記録の機能は、シフト勤務の社会人向けに「夜勤も、明けも、休みも。勤務と給料をひとつに」と言い換えられます。ただし、シフトの型・休み・明けの扱いができてからにしてください。

## 5. やらない方がいいこと・気をつけること

- **「サーバーを持たない・データを集めない」約束を守れる形を選ぶ**
  - 同期は、本人の iCloud の置き場を使えば「開発者は見られない」のままでいられます。自前のサーバーやアカウント登録を作ると、いちばんの強みが消えます。
  - 候補日のリンクは、中身を「#」の後ろに入れて、ページを置いている側にも届かない形にします。
  - 天気は通信が要るので、入れるならオンにした人だけにし、送るのは市区町村だけにします。入れないなら、入れない理由を言葉にします。
- **「書き込まない」と言ってきた約束を、黙って変えない**
  - iPhone のカレンダーへの書き出しを作るなら、最初はオフにし、「LUKKO」という専用のカレンダーにだけ書きます。
  - 許可を求める文・プライバシーポリシー・規約・設定の説明を、同じ版でそろえて書き換えます。
- **学生を置いていかない**
  - 学生向けの言葉や画像を消すのではなく、「使い方の1問」と「別の店頭」で出し分けます。学生を選んだ人には「バイト先」のままにします。
  - 今の利用者が就職したときに、乗り換えずに済む道を作ることが、いちばん確実な社会人の増やし方です。
- **静かな見た目を壊さない**
  - 機能を足すたびに画面へ出すのではなく、設定で出す、見出しの切り替えで選ぶ、を基本にします。
  - 六曜・週の番号・帯の時刻などは、最初はオフにします。
- **ストアで、まだ無い機能を言わない**
  - 「夜勤」「勤務表」のキーワード、「重ねて表示」「同期」などは、できてから入れます。
  - 帯に時刻が出る前に、画像の札に時刻を入れない。
  - ほかのアプリの名前は、キーワードに入れない（規約）。
  - 比べ表に載せるほかのアプリの中身や、新しい iOS の機能（AlarmKit など）、評価の件数は、使う前に最新の状態を確かめる。この一覧の中では確かめきれていないものもあります。
- **お金の約束を守る**
  - いまある機能は無料のまま、定期購読にしない。
  - 選ばれる入口（シフトのスタンプ入力・休みや明けの扱い・通知のボタン・自動の控え）は有料にしない。
  - Pro を出す版では、規約と応援の文を同じ版で直す。
  - 給料や扶養の数字について、助言をしない方針はそのまま守る。
- **通知とお願いは控えめに**
  - 朝のまとめ・週1回の片づけ・控えの知らせ・評価の小窓・7日目の声は、どれも切れるようにして、回数は少なくします。
  - 同じ時期に重ならないよう、ずらします。
- **データを壊さない順番で進める**
  - 同期や自動の控えを作る前に、「起動したとき古いほうの保存から始まる」問題と、「時給を変えると過去の給料が変わる」問題を先に直します。
  - 控えは、古い名前（kimatteru）のものも読めるままにします。
- **大きい工事は一度に始めない**
  - 週表示・重ねて表示・iCloud 同期・共有から予定を作る・Apple Watch・Android は、どれも大きい工事です。
  - 順番は、言葉・見本・ストア（小さい）→ 入力と空き状況 → 取り込みと控え → 大きい工事。
- **海外向けは後回し**
  - 当面は日本だけで配信する前提なので、時差や英語の対応は後でかまいません。
