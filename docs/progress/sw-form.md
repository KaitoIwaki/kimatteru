## Web 版と変えたところ
- 「···」は Web 版（iPhone）のアクションシートではなく、iPhone 標準のメニュー（右上から出る）にした
- 小窓（どうなった？）は中央の箱ではなく、中身の高さに合わせたシートにした（下へ払うと閉じる＝外側を押したのと同じ）
- 新しい予定は「左端からなぞって閉じる」ではなく、シートを下へ払う。書きかけがあれば閉じずに捨てるか聞く
