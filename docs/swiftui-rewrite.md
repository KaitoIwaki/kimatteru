# LUKKO を SwiftUI で作り直す計画

2026-10-14 決定。目的：画面の動き・部品をすべて iPhone の本物にする。機能は1つも減らさない。

## いちばん大事な2つの約束

1. **予定を1件も失わない。** 引っ越しで元のデータを消さない・書き換えない。いつでも元の版に戻せる。
2. **書き直しで不具合を入れない。** 「同じ入力 → 同じ答え」を、いまの JS のコードから取った正解表（ゴールデンテスト）で全部確かめてから出す。

## 確かめる場所（Mac が無い問題の解決）

- リポジトリは公開なので、GitHub の Mac（GitHub Actions の macOS）が無料で使える。
- そこで毎回：ビルド → テスト（iPhone のシミュレーター上）→ 画面のスクリーンショット を自動で行い、結果を手元に取ってくる。
- 画面は、いまの Web 版の同じ見本データのスクリーンショットと並べて比べる。
- 実機（TestFlight）は Codemagic のまま。

## 予定の引っ越し（いちばん慎重に）

いまの保存先：
| 場所 | 中身 | SwiftUI から |
|---|---|---|
| Library/kimatteru-store.json | 予定などすべて（savedAt 付き） | そのまま読める |
| WebView の localStorage `kimatteru.v2` | 同じもの。ファイルより数秒新しいことがある | 直接は読めない |
| Library/（控えのフォルダ） | 毎日の控え | そのまま読める |
| localStorage `lukko.exportMap` | iPhone のカレンダーへ書き出した予定の対応表 | 直接は読めない |
| iCloud（キーと値） | 2台の同期 | そのまま読める |

方針：
1. **同じファイル・同じ形で保存する。** SwiftUI 版も `kimatteru-store.json` に、いまと同じ JSON の形で書く。知らない項目も消さずに残す。→ 元の版に戻しても、そのまま読める。
2. **localStorage も読む。** 初回だけ、アプリの中で見えない WebView を同じ場所（capacitor://localhost）で開いて localStorage を読み、ファイルと savedAt を比べて新しいほうを使う。
3. **元のデータは消さない・上書きしない**（localStorage・控え・iCloud）。引っ越し前の丸ごとの写しも別名で残す。
4. 読み込んだあと、件数・ID・中身を読み返して一致を確かめる。合わなければ、引っ越しを止めて元のまま開く。
5. 引っ越しの確認用に、いろいろな形のデータ（古い版の形・壊れかけ・大量・空）で自動テストする。

## 不具合を入れないために

- いまの JS の計算を、そのまま Node で動かして**正解表**を作る（数千件）。Swift の同じ計算が全部一致するまで出さない。
  - 給料・働いた時間・休憩・深夜、祝日（2020〜2035 の全日）、空き状況の ○△×、くり返し、候補日、延期、
    週と日の時間の並び、通知の時刻、.ics の読み書き、取り込みの重複・種類の推測、まとめの集計、
    検索、最近消した予定（30日）、iCloud の合わせ方、ウィジェットに渡す中身、明けの扱い など
- 画面は、Web 版と SwiftUI 版のスクリーンショットを同じ見本データで並べて比べる。
- 機能の一覧（チェックリスト）を作り、全部 ✓ になるまで出さない。

## 進め方

| 段階 | 中身 | 目安 |
|---|---|---|
| 0. 土台 | GitHub の Mac での自動ビルド・テスト・スクリーンショット、正解表の作成、機能の一覧 | 2〜3日 |
| 1. データと引っ越し | 予定の形（Codable）、保存、引っ越し、iCloud、控え | 3〜5日 |
| 2. 計算 | 正解表に全部合わせる | 1週間 |
| 3. 画面 | 月・週・日・予定・新しい予定・空き状況・まとめ・設定・取り込み・お知らせ・応援・はじめての案内 | 2〜4週間 |
| 4. 試用 | TestFlight で本人が毎日使う（元の版にいつでも戻せる） | 1〜2週間 |
| 5. 公開 | 2.0 として、段階的リリース（少しずつ配る） | — |

- 作業は `swiftui` ブランチで行う。master（いまの版）は不具合の直しだけ続ける。
- いまの版の新機能は、作り直しが終わるまで止める。
- 対応する iOS：**17 以上**。Liquid Glass は iOS 26 の人だけ。
